## 🏭 Where It Runs (Infrastructure)

### **Your Deployment Options**

**Option 1: Hybrid (Recommended for NCC Pilot)**

**Edge Deployment with Acer Veriton NG100 (Blackwell)**

Each pilot deployment typically uses **1–2 Acer Veriton NG100 (Blackwell) edge systems** per site, which host the local Lifetime Agent Foundry runtime and keep sensitive BIM and operational data on-premises in full alignment with **EU NIS2 requirements** and **GDPR-compliant data residency and access control policies**.

**Complete Hybrid Stack:**
- ✅ **Edge hardware:** Acer Veriton NG100 (Blackwell) — Local deployment at your facility
  - Processes all sensitive BIM models locally (never leaves your firewall)
  - Runs agent logic for real-time optimization
  - Meets EU NIS2 critical infrastructure protection requirements
  - Supports 1–2 systems per site (scalable)
- ✅ **Cloud orchestration:** Google Cloud Run (lightweight, stateless)
- ✅ **Inference:** Groq LPU API (ultra-fast decisions <100ms)
- ✅ **Data storage:** Encrypted PostgreSQL + Redis (EU region, GDPR compliant)

**Why Hybrid with Acer NG100?**
- Your BIM data **never leaves your firewall** (edge-only processing)
- Lightning-fast decisions (<100ms) — local processing
- **Full NIS2 compliance** — critical infrastructure protection
- **GDPR data residency** — EU data never crosses borders
- Scales as needed (cloud burst capacity for orchestration)
- Proven Blackwell performance in production environments
