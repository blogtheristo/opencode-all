## 📋 GENEROIDUT ARVOT

Kun generoit salaisuuksia, käytä:

### PowerShell:
```powershell
# Generoi 32-merkkkinen avain (suorita PowerShellissä):
[guid]::NewGuid().ToString().Replace("-","").Substring(0,32)

# Tai käytä online-generaattoria:
# https://cryptotools.net/pass/generate/
```

### Bash (Linux/Mac):
```bash
openssl rand -hex 16
# tai
python3 -c "import secrets; print(secrets.token_hex(16))"
```

## ✅ TARKISTUSOHJE

### 1. Avaa .env.mcp tekstieditorissa
```powershell
code .env.mcp
# tai
notepad .env.mcp
```

### 2. Täytä kriittiset (PUNAINEN)
Etsi ja korvaa:
```env
# Ennen:
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_KEY=your-supabase-service-role-key-here

# Jälkeen:
SUPABASE_URL=https://abcdef123456.supabase.co
SUPABASE_SERVICE_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

### 3. Tallenna ja testaa
```powershell
cd "D:\Proton\My files\2026\Repos2026\dws6"
pwsh -File .\scripts\Open-EnvTerminal.ps1
```

### 4. Tarkista että muuttujat latautuivat
```powershell

$env:ANTHROPIC_API_KEY
# Molempien pitäisi näyttää arvo
```

## 📚 APUA

### Missä löydät arvot?

| Muuttuja | Paikka | URL |
|----------|--------|-----|
| `SUPABASE_URL` | Supabase → Settings → API | https://app.supabase.com |
| `SUPABASE_SERVICE_KEY` | Supabase → Settings → API | https://app.supabase.com |
| `ANTHROPIC_API_KEY` | Anthropic → Account → API Keys | https://console.anthropic.com/account/keys |
| `GROQ_API_KEY` | Groq → Console → API Keys | https://console.groq.com/keys |
| `GOOGLE_API_KEY` | Google Studio | https://aistudio.google.com/app/apikey |
| `STRIPE_SECRET_KEY` | Stripe → Developers → API Keys | https://dashboard.stripe.com/apikeys |
| `PAYPAL_CLIENT_ID` | PayPal → Developer → Credentials | https://developer.paypal.com/dashboard/ |

### Ongelmat?

**"Ei muuttujia ladattu"**
```powershell
# Tarkista että .env.mcp on olemassa:
Test-Path ".env.mcp"  # Should return: True

# Tarkista että muuttujat ovat oikeassa muodossa:
Get-Content ".env.mcp" | Select-Object -First 10
```

**"Supabase yhteysvika"**
- Tarkista `SUPABASE_URL` on oikea
- Tarkista `SUPABASE_SERVICE_KEY` ei ole truncated (se on pitkä!)

**"API key ei toimi"**
- Varmista key on aktiivinen palvelun hallintapaneelissa
- Varmista key on oikea (dev vs prod)
