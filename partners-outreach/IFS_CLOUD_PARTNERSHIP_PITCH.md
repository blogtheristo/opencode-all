## Pitch: IFS ISV Partner Application

**Subject: ISV Partner Application — Automated CSRD/ETS/CBAM Compliance from IFS Cloud Data**

To the IFS Partner Team,

We're DWS IQ, a Finnish operations compliance platform that automates EU regulatory reporting (CSRD, ETS, CBAM) by pulling data directly from ERP systems. We have a working IFS Cloud connector that reads asset registers, work orders, energy data, and project information — and transforms it into regulator-ready compliance reports.

**The problem your customers face:** 49,000 EU companies must file CSRD reports. Many of them run IFS Cloud for asset and project management. Today, they manually export data from IFS, process it in Excel, and hire consultants to produce compliance reports. This costs €50-250k/year and 40+ hours/month.

**What DWS IQ does:** We connect to IFS Cloud via REST API (projection URLs, OAuth2), pull operational data automatically, map it to ESRS disclosure requirements, and generate audit-ready CSRD/ETS/CBAM reports quarterly. No manual exports. No consultants for data collection.

**Our IFS connector status:**

- Real IFS Cloud projection URLs (verified)
- OAuth2 authentication (production-ready)
- 14-field asset mapping across 6 entity types
- 5 of 6 sync methods make real HTTP calls
- Closest to production of our 6 ERP connectors

**What we're asking:**

1. ISV Partner status to list on IFS Marketplace
2. Access to IFS Cloud sandbox for integration testing and certification
3. Co-marketing to Nordic construction/manufacturing customers facing CSRD deadlines

**About us:**
