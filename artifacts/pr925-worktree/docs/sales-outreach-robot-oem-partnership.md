## Handling the "Tiny Finnish Firm" Objection

This will come up in every serious DD conversation. Prepared responses:

**Objection:** "You're a small Finnish company. How can you support 27 EU countries?"

**Response framework:**

1. **The compliance layer is software, not people.** Article 12 logging runs on the customer's own GN-100 NVIDIA cluster. It doesn't need a DWS office in every country — it needs a correctly configured logging layer at each site.

2. **Partner ecosystem model.** We work with existing system integrators in each market (Siemens partners, ABB channel, local OT integrators). DWS provides the compliance software + technical file; the local integrator handles installation.

3. **Finland is a feature, not a bug.** EU data residency from a non-CLOUD Act country. Finnish GDPR enforcement (Tietosuojavaltuutetun toimisto) is among the most rigorous in the EU. Customers get sovereignty by default.

4. **Small ≠ unproven.** 16 AI agents operational. GN-100 hardware running in production. 4-partner stack (Acer, NVIDIA, Siemens, ABB) already integrated. The compliance layer is live — not a pitch deck.

5. **Proof point:** Offer a 30-day technical evaluation with the customer's own use case on DWS-hosted GN-100. Results speak louder than headcount.
