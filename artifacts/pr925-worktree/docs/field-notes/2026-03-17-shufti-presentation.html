What's Already Built

DWS side of the integration is architected and partially implemented

DWS — Ready

  • KYA policy engine (Shanghai Model)
  • Agent Trust Score calculator (ATS)
  • Shufti webhook handler (HMAC-SHA256)
  • Event bus integration
  • Sandbox permission gating (4 levels)
  • Firehorse audit trail (EU AI Act Art. 12)
  • Onboarding routes (/api/v1/onboard)

Need from Shufti

  • API sandbox/test credentials
  • Webhook documentation (schema, retry)
  • KYB (business verification) API access
  • Risk score format details (continuous? sub-scores?)
  • Webhook delivery SLA and reliability
  • EU data residency confirmation

We are not asking Shufti to build anything new. We need API access and documentation to connect existing Shufti capabilities to our KYA engine.

PoC Demo Scenario

End-to-end: onboarding → BYO deploy → risk flag → sandbox restricts

Step 1

User onboards via Shufti IDV

Document + face verification. KYA L1 score = 90. Full sandbox access granted.

Step 2

User deploys BYO agent

Agent manifest reviewed. KYB org check passes. Agent enters sandbox with approved tools.

Step 3

Shufti flags AML hit

Webhook fires. KYA L5 signal. New risk score = 35. Policy engine triggered.

Step 4

Sandbox restricts in real-time

Agent egress blocked. Filesystem read-only. Human review required. All within 5 seconds.
