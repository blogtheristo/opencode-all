**Status:** Development (2026-01-11)  
**Purpose:** Quick setup guide for filling in critical environment variables

## Overview

Your `.env.mcp` file has been created with placeholder values. This guide helps you fill in the **essential** variables for development.

## Step 1: Create Supabase Project (10 mins)

### 1.1 Sign Up & Create Project

1. Go to **https://supabase.com** and sign up (free)
2. Click **"New Project"**
3. Fill in:
   - **Name:** `dws-iq-6` (or your preference)
   - **Database Password:** Generate and save securely
   - **Region:** `eu-central-1` (Europe) - choose closest to you
4. Wait 2-3 minutes for provisioning

### 1.2 Get Your Credentials

1. Open your Supabase dashboard
2. Go to **Settings** → **API**
3. Copy these three values:
   ```

   Service Role Key (secret): eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
   Anon Key: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
   ```

## Step 2: Get Anthropic API Key (5 mins)

### 2.1 Sign Up for Anthropic

1. Go to **https://console.anthropic.com/account/keys**
2. Sign up or log in with your account
3. Go to **API Keys** section
4. Click **"Create Key"**
5. Copy the key (starts with `sk-ant-`)

### 2.2 Update .env.mcp

```env
# BEFORE:
ANTHROPIC_API_KEY=sk-ant-...

# AFTER (example):
ANTHROPIC_API_KEY=sk-ant-abcdef123456789abcdef123456789
```

## Troubleshooting

### "Cannot find '.env.mcp'"

```powershell
# Make sure .env.mcp exists in project root:
cd "D:\Proton\My files\2026\Repos2026\dws6"
Test-Path ".env.mcp"  # Should show: True

# If False, rerun creation:
Copy-Item -Path "env.mcp.example" -Destination ".env.mcp" -Force
```

### Supabase Connection Failed

- Verify `SUPABASE_URL` matches your project dashboard
- Check `SUPABASE_SERVICE_KEY` is not truncated (it's long!)
- Make sure you copied from **Settings → API**, not elsewhere

### Anthropic API Key Not Working

- Verify key starts with `sk-ant-`
- Check you have API credits (not just signed up)
- Go to https://console.anthropic.com/account/billing/overview to add credits
