## Executive Summary

**Kolme tasoa — yksi strategia.**

| Taso           | Tuote / Malli              | Rooli                                                 |
| -------------- | -------------------------- | ----------------------------------------------------- |
| **Ympäristö**  | DWS IQ 6                   | 18 agenttia, 32 tuotetta, AI-avusteinen kehitysalusta |
| **Johtohanke** | DWS IQ Aegis               | Sovereign AI -pilottialusta 13.2-paradigmalle         |
| **Muisti**     | LWM (Lifetime World Model) | Fyysinen teollisuustieto — pysyvä world model         |

Paradigman muutos ei ole versiopäivitys. Se on **uusi tuotantomalli**. Nuorille suunnatuissa hankkeissa 9.2 → 9.3 → 9.4 kehitys tapahtui AI-avusteisesti mutta vanhan prosessiajattelun sisällä. **13.2 on ensimmäinen versio, jossa tekoäly on tuottaja — ihminen orkestroi.**

## 1. Suomen tilanne — Lähtöasetelma

### 1.1 Kaksi aaltoa

```
Aalto 1: AI-avusteinen kehitys (2024–2025)
─────────────────────────────────────────
9.1 → 9.2 → 9.3 → 9.4
Koodin laatu ↑  |  Prosessi sama  |  Cutoff: 31.12.2025

Aalto 2: AI-natiivirakenne (2026→)
─────────────────────────────────────────
13.2 → ...
Tekoäly tuottaa versiot  |  Ihminen orkestroi  |  10× nopeus  |  1/10 kustannus
```

### 1.2 Miksi hyppäys 9.x → 13.2 (ei 9.5)

Versioloikka on intentionaalinen. Aspire-ekosysteemi teki täsmälleen saman siirron:
Microsoft hyppäsi 9.5 → 13.0 .NET Conf 2025:ssä decouplaten versioinnin .NET:n
sykliltä. DWS:n 13.2 on strateginen signaali samaa logiikkaa käyttäen:

- **9.x** = AI-avusteinen vanha malli (legacy of thought)
- **13.2** = AI-natiivi uusi paradigma (first principles rebuild)

Numerot kommunikoivat ulospäin. Asiakas, partneri ja sijoittaja näkee suoraan,
että kyse ei ole inkrementaalisesta päivityksestä.

## 2. Nuorille — Hankkeet 9.2, 9.3, 9.4

### 2.1 Strateginen tarkoitus

"Nuorille" viittaa suomalaisiin yrityksiin ja organisaatioihin, jotka ovat
**paradigman muutoksen kynnyksellä** — ne ovat tuottaneet 9.x-laadun tuotteita,
mutta eivät ole vielä tehneet siirtoa 13.2-tuotantomalliin.

Nämä ovat juuri niitä yrityksiä, joille DWS IQ Aegis + LWM Strategy on
eniten merkityksellinen: ne tarvitsevat **johtohankkeen** todistamaan, että
siirto on mahdollinen ja turvallinen.

### 2.2 Hankkeiden kuvaus

| Hanke       | Versio | Kuvaus                                                                     | Oppi 13.2:lle                                    |
| ----------- | ------ | -------------------------------------------------------------------------- | ------------------------------------------------ |
| **Hanke A** | 9.2    | AI-avusteinen koodin laadunparannus — sama arkkitehtuuri, parempi toteutus | Proof: AI parantaa laatua ilman prosessimuutosta |
| **Hanke B** | 9.3    | AI-generoidut testit + CI/CD-integraatio                                   | Proof: AI-agentit korvaavat manuaalisen QA:n     |
| **Hanke C** | 9.4    | AI-pohjainen dokumentaatio + API-generaatio                                | Proof: Ihminen orkestroi, AI tuottaa             |

**Ydin:** 9.2–9.4 ovat **oppimisvaihe** — ne todistivat, mitä AI pystyy tekemään
vanhan mallin sisällä. 13.2 on **harppaus**: rakennetaan uusi malli alusta.

### 2.3 Mitä 9.x-yrityksille ehdotetaan

Kolmen askeleen siirtymä:

```
Askel 1 — Hyväksy tilanne (ei tunnereaktio, vaan analyysi)
  ↓ "Kilpailijamme on jo 13.2-nopeudella. Meillä on X kuukautta."

Askel 2 — Pilotoi Aegis (sovereign, hallittu, EU-vaatimustenmukainen)
  ↓ Yksi hanke → AI-natiivirakenne → mitattu tulos

Askel 3 — Skaalaa LWM:n avulla (toimialan world model → pysyvä kilpailuetu)
  ↓ Tieto kertyy malliin — ei katoa kun projekti loppuu
```

## 4. DWS IQ Aegis — Sovereign AI Platform

### 4.1 Tuoteprofiili

**Aegis** on single-tenant sovereign AI-alusta, joka mahdollistaa 13.2-paradigman
käyttöönoton yrityksessä ilman data sovereignty -riskiä.

| Ominaisuus                | Arvo                                  |
| ------------------------- | ------------------------------------- |
| Deploy                    | UpCloud Helsinki / EU-data residency  |
| Arkkitehtuuri             | Managed Kubernetes (single-tenant)    |
| Compliance                | EU AI Act Article 12, GDPR, CBAM/CSRD |
| Hinta                     | EUR 59,990 + EUR 999/kk               |
| Marginaali (30 asiakasta) | ~54 % infra gross margin              |
| Breakeven                 | ~5 asiakasta                          |

### 4.2 Miksi Aegis on 13.2-johtohankkeen alusta

Suurin este 13.2-paradigman käyttöönotolle suomalaisissa yrityksissä ei ole
tekninen — se on **luottamus ja hallinta**:

- "Minne meidän data menee?"
- "Kuka auditoi agentit?"
- "Miten todistamme regulaattorille?"

Aegis vastaa kaikkiin kolmeen:

1. **Data Helsinki-konesalissa** — UpCloud EU, ei CLOUD Act -altistumaa
2. **EU AI Act Article 12 -auditloki** — jokainen agenttioperaatio lokitettu
3. **Signed reports** — Firehorse-moduuli tuottaa allekirjoitetut raportit

## 5. LWM — Lifetime World Model

### 5.1 Miksi LWM on strategian muistikerros

LWM (Lifetime World Model) on DWS:n vastaus kysymykseen:

> "Mitä tapahtuu, kun projekti loppuu?"

Perinteisessä mallissa tieto häviää henkilöiden mukana. LWM:ssä tieto kertyy
**pysyvään temporal latent space -malliin** — rakennushankkeen fyysinen historia
jää elämään digitaalisena, hakukelpoisten agenttikyselyiden kohteena.

### 5.2 LWM ja 13.2-strategia

```
9.x-malli:        Projekti → Raportti → Arkisto → Tieto katoaa
13.2 + LWM:       Projekti → LWM → Pysyvä muisti → Seuraava projekti oppii
```

LWM muuttaa konsultoinnin **kumulatiiviseksi** — jokainen hanke tekee
seuraavasta paremman. Tämä on Lifetime Oy:n pitkän aikavälin kilpailuetu, jota
yksittäinen konsultti tai perinteinen IT-projekti ei pysty replikoimaan.
