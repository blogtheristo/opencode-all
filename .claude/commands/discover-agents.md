Discover DWS IQ agents by capability.

Usage: /discover-agents <capability>

Input: $ARGUMENTS

Steps:
1. Run: `cd cli && npx tsx src/cli.ts discover <capability>`
2. Present the matching agents with their names, descriptions, and full capability lists
3. Suggest which agent to run based on the user's likely intent

Example capabilities: compliance, carbon, construction, seo, emissions, logistics, safety, financial, research, outreach
