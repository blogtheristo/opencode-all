Load and follow the full procedure in `skills/token-capital/SKILL.md`. Canonical framework:
`docs/field-notes/2026-06-15-human-token-capital.md`. Note: token capital ≠ token spend — it

Input: $ARGUMENTS (firm / customer / AI stack, or a natural-language description).

## Steps

1. Read `skills/token-capital/SKILL.md` and apply it.
2. Inventory the four loop components (private evals, private RL env, knowledge base, the loop itself); grep the stack for the artefacts.
3. Run the sovereignty test — model-swap survival: SOVEREIGN | PARTIAL | RENTING.
4. Score compounding: CLOSED LOOP vs OPEN LOOP (does each run improve the next?).
5. Emit the Output-contract block; name missing components and the next loop-closing artefact.
6. Compose with `/sovereignty-assess`, `/kb`, `/learn`, `/dream-on`; pair with `/human-capital` for direction.
