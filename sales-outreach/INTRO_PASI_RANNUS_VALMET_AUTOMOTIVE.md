## The wedge — "Industrial excellence is sovereign only if the AI layer is sovereign"

Antti Havola's Telia Smart Industry talk (May 2026) made the public case: Valmet Automotive's edge is the ability to renew, scale, and apply hard-earned automotive-grade manufacturing excellence to new contexts — defense first. The named stack: smart manufacturing, robotics, simulation, advanced production technologies, connectivity, private 5G.

That stack is sovereign at the OT layer by construction. Private 5G keeps the radio inside the fence. Robotics and simulation run on factory infrastructure. Connectivity is Telia, an EU operator. What is **not** sovereign by default is the AI layer that increasingly sits on top:

- Generative-AI copilots for production engineers (process documentation, root-cause)
- Simulation surrogates and digital-twin inference
- Customer-disclosure generation (Mercedes-Benz Scope 3 audits, CBAM, CSRD for the automotive product, defense-customer security documentation)
- Robotics fleet diagnostics, OEE analytics, predictive maintenance with LLM summarization

If any of those run on US hyperscaler AI, three consequences follow:

1. **Defense exposure.** EU defence-fund-eligible work, Finnish Defence Forces, and NATO-standard procurement increasingly require sovereign-AI attestations. Cloud Act exposure on simulation, process documentation, or operator-facing assistance is disqualifying — even when the OT data never crosses the fence.
2. **Automotive Scope 3 disclosure leak.** Mercedes-Benz, the principal Uusikaupunki customer, runs deepening Scope 3 audits. The same is true for any future automotive client. Every disclosure generated through US-hosted AI is a copy of process detail outside the EU perimeter.
3. **Private 5G claim breaks at the AI seam.** "Our factory data never leaves the campus" is true at the radio. It becomes untrue the moment an AI tool ingests historian data and a vendor stores prompts.

DWS IQ closes that gap: a sovereign, EU-hosted, KYA-governed AI layer that sits on top of the private-5G + OT stack already in place.
