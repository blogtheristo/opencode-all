## Description
**Legacy / Alternative Tier.**

The proven precursor to DWS IQ 6, supporting established industrial workflows. It remains a robust choice for specific legacy environments.

## Why DWS IQ 5?
**The Compliance Bridge.**
For organizations not yet ready for the full AI-native DWS IQ 6, Version 5 provides a stable bridge to "Fit for 55" compliance. It ensures you aren't left behind as reporting requirements tighten. **It is serious marketing with penalty if not done properly.**

**At the end of the day, it keeps your legacy operations compliant while you plan for the future.**

## The Bridge Methodology
**"Stabilize then Modernize."**
DWS IQ 5 focuses on stability and connectivity for older industrial protocols:
*   **Compatibility:** Native support for older OPC-UA and Modbus versions.
*   **Stability:** Proven, monolithic architecture.
*   **Path Forward:** Built-in data exporters to migrate easily to IQ 6.

## Usage Scenario: The Retrofit Factory
**A factory runs on 15-year-old PLCs and cannot support edge AI.**

**DWS IQ 5 secures the data:**
1.  **Connect:** It utilizes legacy drivers to poll the PLCs.
2.  **Buffer:** It stores data locally to handle unstable internet connections.
3.  **Report:** It generates standard CSV reports for the central office.
4.  **Outcome:** The factory participates in the corporate carbon reporting without a hardware overhaul.

## Expected Impact & Efficiency
*   **Extended asset life**
    *   *How:* Connecting legacy machines to modern reporting.
*   **Risk mitigation**
    *   *How:* Ensuring older sites aren't compliance blind spots.

## The 5 DWS IQ 5 Components
1.  **Legacy Poller:** Reads data from older industrial protocols.
2.  **Local Buffer:** Ensures data integrity during outages.
3.  **Sync Engine:** Uploads data to the cloud when available.
4.  **Report Generator:** Basic template-based reporting.
5.  **Migration Agent:** Tools to assist in moving to IQ 6.

## Technical Specifications
*   **Architecture:** Monolithic .NET/Java application.
*   **Protocols:** Modbus, OPC-DA, CSV import.
*   **Requirements:** Windows Server 2016+ or Linux.
