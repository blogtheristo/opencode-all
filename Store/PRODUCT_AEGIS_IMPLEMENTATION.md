# DWS IQ Aegis Implementation Programme

**Three phases, three months, one agent live and a world model that starts accumulating** — delivered alongside DWS IQ Aegis

## What it is

A structured implementation engagement for organisations that have decided on Aegis and want the deployment carried through to a working, knowledge-accumulating state rather than handed over at go-live.

It is **not** an evaluation. If you are still deciding whether local-first operation suits your site, the bounded evaluation engagement is the right starting point instead — see Related below.

## The three phases

| Phase | Duration | Outcome | Price |
| --- | --- | --- | --- |
| **1 — Operational audit** | 2 weeks | Current state mapped to a gap analysis against the target architecture | €5,000 |
| **2 — Agent in production** | 6 weeks | One skilled agent live and EU-compliant, with the Article 12 record running | €15,000 |
| **3 — LWM integration** | 8 weeks | World-model integration, so operational knowledge accumulates instead of resetting | €25,000 |

**Phase 1 — Operational audit (2 weeks, €5,000).** Control-room workflow mapping, security boundary verification, risk analysis and edge hardware readiness assessment, producing a gap analysis against the target architecture.

**Phase 2 — Agent in production (6 weeks, €15,000).** Staged production deployment of the domain-specific agents, configuration of local identity and the Article 12 audit trail, and operator kill-switch training.

**Phase 3 — LWM integration (8 weeks, €25,000).** World-model telemetry synchronisation, CAD/BIM/SCADA data pipeline hookups, and multi-site reporting.

Phases run in sequence by default. They can be taken individually where the earlier work already exists.

## Pricing, stated plainly

| | |
| --- | --- |
| **Price** | €45,000 for all three phases |
| **Duration** | ~3 months |
| **Relationship to Aegis** | **Additive.** Charged alongside Aegis onboarding (€59,990) and licence (from €999/mo) |
| **Credit** | **None.** This programme is not credited against onboarding |

**Why it is not credited, when the evaluation engagement is.** Phase 3 — LWM integration — is work that Aegis onboarding does not contain. Crediting it against onboarding would mean charging once for two different pieces of work, which does not survive procurement review and should not. Phases 1 and 2 sit closer to onboarding, which is why they are priced separately and can be taken on their own.

## Who it is for

Organisations that have already committed to Aegis and want the accumulation layer built, not just the platform switched on. Typically a second engagement after a bounded evaluation, or a first engagement where the architecture decision is already settled internally.
