## 🎯 Current Sales Messaging (Q1 2026)

### Core Message: "Fit for 55 Means Fit for 55"

> **Fit for 55 and CSRD targets did not change after Omnibus – only the paperwork did.**

Boards are still responsible for real emissions, not minimum forms.

### Key Points:

1. **Omnibus simplified reporting, not emissions reduction**
2. **2030 targets unchanged: 55% GHG reduction**
3. **EPBD deadlines unchanged: Public 2027, Private 2030**
4. **ETS expansion unchanged: Construction, logistics, healthcare by 2027**
