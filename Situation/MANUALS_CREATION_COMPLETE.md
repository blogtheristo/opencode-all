## 📖 Converting to PDF

### Method 1: Using Pandoc (Recommended)
```bash
# Install pandoc
sudo apt-get install pandoc texlive-latex-base

# Convert to PDF
pandoc Situation/DWS_IQ6_ADMINISTRATOR_MANUAL.md \
  -o DWS_IQ6_ADMINISTRATOR_MANUAL.pdf \
  --pdf-engine=xelatex \
  --toc \
  --toc-depth=3 \
  --number-sections \
  -V geometry:margin=1in \
  -V fontsize=11pt \
  -V documentclass=report
```

### Method 2: Using Markdown to PDF Tools
```bash
# Using markdown-pdf (Node.js)
npm install -g markdown-pdf
markdown-pdf Situation/DWS_IQ6_ADMINISTRATOR_MANUAL.md

# Using grip (GitHub-style)
pip install grip
grip Situation/DWS_IQ6_ADMINISTRATOR_MANUAL.md --export DWS_IQ6_ADMINISTRATOR_MANUAL.html
# Then print to PDF from browser
```

### Method 3: Using VS Code Extension
1. Install "Markdown PDF" extension in VS Code
2. Open `DWS_IQ6_ADMINISTRATOR_MANUAL.md`
3. Right-click → "Markdown PDF: Export (pdf)"
