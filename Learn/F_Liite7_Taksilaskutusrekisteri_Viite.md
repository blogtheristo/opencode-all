## Asiakirjan kuvaus

Taksilaskutusrekisteri on Lifetime Oy:n kirjanpidossa ylläpidetty päivätason rekisteri kaikista taksitoiminnasta (Taxivirpi / Helpbus / Pohjolan Kaupunkiliikenne / Nobina) laskutetuista provisiotuloista vuodesta 2010 alkaen.

**Alkuperäinen rekisteri sijaitsee:**
- Lemonsoft-kirjanpitojärjestelmässä (kirjanpitäjän hallinnassa)
- Google Sheets -laskutustaulukossa (kirjanpitäjän ylläpitämä)

---

## Rekisterin merkitys aktivoinnille

Taksilaskutusrekisteri on Kirjaus 2:n (494 000 EUR) pääevidenssi **käänteiskirjausmenetelmässä**:

| Periaate | Selitys |
| :--- | :--- |
| Taksipäivä kirjattu | → EI R&D-työtä kyseisellä päivällä |
| Ei taksipäivää kirjattu | → R&D-työtä DWS-tuotekehityksessä |
| Viikonloput / pyhät | → Vähennetty erikseen |
| Lopputulos | → R&D-päivät = kaikki arkipäivät joilta ei taksilaskua |

Tämä menetelmä on **vahvempi kuin positiivinen tuntikirjaus**, koska se perustuu kolmannen osapuolen kirjanpidollisesti vahvistettuun rahaliikenteeseen, jota ei voi muuttaa jälkikäteen.

## Kuinka rekisteri toimitetaan kirjanpitäjälle

Rekisterin toimittaminen uudelle kirjanpitäjälle (rantalainen.fi):

1. **Lemonsoft-export:** Kirjanpitäjä (aiempi) toimittaa taksituottojen päivätason kirjanpidon Lemonsoft-exporttina uudelle kirjanpitäjälle
2. **Google Sheets -siirto:** Taksilaskutus-Sheets siirretään uuden kirjanpitäjän käyttöön
3. **Periodi:** 12/2019–30.09.2025 (Kirjaus 2:n ajanjakso)
