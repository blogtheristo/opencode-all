1. Tutkimuksen tausta

Eurooppalaisten teollisuuden pk-yritysten kaksoissiirtymä:

  • Digitaalinen muutos — tekoäly, automaatio, reaaliaikainen päätöksenteko
  • Vihreä siirtymä — EU Fit for 55 (–55 % päästöt 2030), sisältyvän hiilen mittaus 2028

Perinteisten SaaS-alustojen ongelmat:

  • Hinta €1 400+/kk — pk-yritykselle liikaa
  • Vain pilvi → korkea latenssi, korkeat käyttökustannukset
  • Ei toimialakohtaista compliance-työnkulkua

Henkilökohtainen ajuri: Microsoft for Startups -ohjelma päättyi 02/2025 → tarvittiin edullisempi tuotantotapa. Cloudflare + Cursor AI + Claude Code mahdollistivat uuden mallin elokuusta 2025 alkaen.

2. Tutkimusongelma

Päätutkimuskysymys: Miten AI-avusteisesti kehitetty teollinen AI-alusta voi saavuttaa tuote-markkinasopivuuden hybridissä pilvi–edge-toimintamallissa säilyttäen alle €400/kk käyttökustannukset?

Viisi alatutkimuskysymystä:

  1. Tuote ja liiketoiminta — kansainvälisesti skaalautuva asiakaslupaus
  2. Teknologia — palvelutuote pilvi + edge + verkkokauppa
  3. Teknisten ratkaisujen evaluointi — paras arkkitehtuuri
  4. Yritysturvallisuus — NIS 2, EU AI Act, GDPR, Cybersecurity Act
  5. Verkkokauppavalidointi (V3.0) — automatisoitu kauppa PMF-validaattorina

6. Lifetime Scope Signals -protokolla

Tutkimuksen uusi teoreettinen kontribuutio:

  • Deklaratiivinen koordinointiprotokolla moniagenttijärjestelmille
  • Deterministiset riippuvuudet — käynnistysvaiheen optimointi
  • Signaalit: READY · COMPLETE · ERROR · BLOCKED

Neljä työnkulkumallia MCP Hubin kautta:

  1. Fan-Out — rinnakkainen suoritus
  2. Sequential — peräkkäinen ketju
  3. Reflection — itsekorjaava silmukka
  4. Pipeline — vaiheistettu putki

Vaikutus: toistettava, auditoitava, EU AI Act artikla 12 -yhteensopiva agenttiorkestraatio.

10. EU-sääntelyvalli

16 EU-toimialan Fit for 55 -vaikutusanalyysi

  • Taso 1 (8): suora ETS + CBAM — sähkö, teräs, sementti, kemia, lento, meri, maantie, rakentaminen
