Purpose

This index maps repository documents and standards to their corresponding web domain pages.

When a document is updated, check this index to identify which web pages need to be reviewed or updated. This prevents documentation drift between the repo and live web properties.

Rule (DWS_DOCUMENT_STANDARD.md §17): After every document update, the author MUST consult this index and note which web pages are affected in the PR description.

How to Use

  1. Find your document in the left column
  2. Check the web pages in the right columns (dws10.com, dws6.com, onelifetime.world)
  3. Review the listed pages — do they reflect your document change?
  4. Update web pages if content is stale (root folder first, then landing-pages/)
  5. Record in PR: "Web check: /page reviewed [no change | updated]"

Post-Update Web Check Procedure

POST-UPDATE WEB CHECK

Step 1 — Look up document in docs/WEB_CONTENT_INDEX.md
Step 2 — For each mapped web page:
          a. Check: does page content reflect the doc change?
          b. If YES → no action, record "reviewed, no change"
          c. If NO  → update the HTML page (root first, then landing-pages/)
Step 3 — Record in PR description:
          "Web check: /page-name reviewed [no change | updated]"
Step 4 — Run: diff <root-page> <landing-pages-copy>  → must be empty
