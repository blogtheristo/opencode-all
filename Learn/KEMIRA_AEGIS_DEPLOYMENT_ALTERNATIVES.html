The Two Alternatives

A · Sovereign EU Cloud (UpCloud Helsinki)

Recommended start

Canonical software-only Aegis on UpCloud Managed Kubernetes, Helsinki (Finnish-owned, ISO 27001, CISPE, zero CLOUD Act). L40S inference in the EU enclave.

  • Hardware: none
  • Sovereignty: EU-sovereign managed cloud
  • Speed: fastest — GA Aug 2026
  • Price: Standard €59,990 + €999/mo · Defence €89,990 + €1,999/mo

Trade-off: data on a Finnish sovereign managed cloud, not physically in the plant. Sufficient for most CSRD/ETS/PCF work.

B · On-Prem / Air-Gapped — one per factory (Aegis Sovereign)

Maximum sovereignty

Aegis Sovereign air-gapped on a Kemira-owned DWS appliance — a Control Room (single GN100 node) or Situation Room (2× GN100 bridged + model bundle) on each factory's network, fed by edge sensor nodes. Aegis stays software-only; the appliance is customer-owned CAPEX.

  • Hardware: Control Room €5,294 · Situation Room €10,093 — turnkey, on-site install incl.
  • On-site models: NVIDIA bundle (vision, acoustic, language, reasoning, voice)
  • Sovereignty: air-gapped; data never leaves the site
  • Price: Sovereign Custom + €4,999/mo software + appliance CAPEX

Trade-off: appliance CAPEX, per-site footprint. In return: a canonical turnkey product with set pricing, on-site install, strongest sovereignty + owned asset. One unit per factory; scale by adding units.

Recommendation

Start with Alternative A for the Fiber Essentials pilot aligned to Aegis GA — fastest path to measured cycle-time, audit coverage, and hours reclaimed, full EU sovereignty, no hardware to own. Reserve Alternative B — a DWS Control Room or Situation Room per factory — for sites where process/recipe sensitivity demands a physical air-gap or Kemira prefers a CAPEX-owned asset. Not exclusive: pilot on cloud, place an appliance on-prem where sovereignty requires. Identical Aegis agents and audit chain either way — the choice is deployment topology, not capability.

Assumptions & Caveats

  1. Pricing is canonical — Aegis tiers from Store/PRODUCT_AEGIS.md; appliance prices (Control Room €5,294, Situation Room €10,093) from dws10.com/config/products.json. Aegis bundles no hardware; the appliance is a separate customer-owned CAPEX line.
  2. Deterministic scoring (Rule 5): Scope 1/2/3, ESRS coverage, ETS and PCF computed by testable code; LLM only drafts, gap-analyses, cites.
  3. CBAM scope is narrow today — most of Kemira's chemistry is out of scope; value mainly in imported precursors / hydrogen. Confirm in scoping.
  4. Appliance sizing: Control Room (single GN100) vs Situation Room (bridged pair) to the site's model bundle and load; a DGX-class node is the upper rung for 1M-token-context flagship workloads.
  5. Assurance still needs a human auditor. Aegis accelerates and traces; it does not replace the assurer.
  6. Figures tagged (confirm) are single-source from the board deck — validate with Kemira before board circulation.
