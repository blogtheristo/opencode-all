Overview: The New Workflow

You now have three integrated systems working together to keep you on track:

  • Learn Dashboard — Shows today's calendar deadlines & meetings with PRIORITY 1 urgency marking
  • Mission Control — Triage queue for customer/investor/partner work items

Before: Deadlines and meetings lived only in .md files or your head. Result: missed calls, expired offers, late replies.
Now: Every deadline automatically shows up with PRIORITY 1 marking. You see it every morning.

Understanding PRIORITY 1 Marking

⚠️ CRITICAL RULE

If a task has a gate deadline (DL), it MUST be marked PRIORITY 1. Otherwise you will skip important deadlines and miss meetings.

What Gets PRIORITY 1?

  • ⏰ Meetings — Any scheduled call/meeting today
  • 📋 Deadline expiries — Offers expire, proposals due, contracts sign by date
  • 🎯 Gate-gated tasks — Any task with a "must-do-by" date
  • 🚨 Compliance dates — Regulatory deadlines, license renewals, regulatory reports

What Does NOT Get PRIORITY 1?

  • 📧 Regular email (triage later via Mission Control)
  • 📝 Drafts or work-in-progress items
  • 🔔 Information-only notes

How It Works

When an agent or tool creates a task with a deadline, it automatically tags it in Google Calendar. The Learn Dashboard reads your calendar and shows every event with a time as PRIORITY 1.

Understanding the Async Queue

What Is It?

The Async Queue lets you queue work for OpenCode agents to process overnight or throughout the day, without requiring your immediate attention.

Queue Status on Learn Dashboard

  • ⏳ Queued — Items waiting to be picked up by an agent
  • ✓ Completed — Items agents finished processing. Results ready.

How to Queue Work

  1. In Mission Control, find an item that needs raw data handling (e.g., complex proposal analysis)
  2. Click "Queue for Async" button
  3. A modal pops up: enter title, centre, context
  4. Submit. Item goes into .workflows/opencode-all/queue.jsonl
  5. OpenCode agents start processing (immediately or on next interval)
  6. Next morning, check Learn Dashboard: see ✓ Completed count

Example Workflow

Monday 04:30 UTC: You queue 5 investor due-diligence packs for OpenCode. Status: ⏳ 5 Queued.

Monday–Tuesday overnight: OpenCode agents work through them, write findings to handoff files at .claude/handoffs/opencode-batch/.

Tuesday 04:30 UTC: Learn Dashboard shows ✓ 5 Completed. Results ready in Mission Control for you to review and send to investors.

✓ The Benefit

Complex work (research, data analysis, proposal drafting) happens while you sleep. You wake up with the results ready to review and send. Zero time wasted.

FAQ & Troubleshooting

Q: A deadline isn't showing in Learn Dashboard. Why?

A: Three possibilities:

  • The calendar event has no time set (all-day events don't trigger PRIORITY 1)
  • The event was added after 07:30 UTC today (it'll show tomorrow at 04:30)
  • The event is on tomorrow's date, not today

Fix: Click "Refresh Now" button to force an immediate update.

Q: How do I add a deadline manually if I don't have a calendar event yet?

A: Use Google Calendar to create the event. Search: "Google Calendar" → sign in → "Create" → enter date/time → save. It'll appear in Learn Dashboard at the next auto-refresh (every 3 min).

Q: The queue is stuck. No items are processing. What do I do?

A: Check .workflows/opencode-all/queue.jsonl in the repo. If the file is locked or corrupted, contact your OpenCode admin. If items show "state": "IN_PROGRESS" but have been there >2 hours, manually reset to PENDING.

Q: Can I see which agent processed each queue item?

A: Yes. Each queue entry has a handoffPath (e.g., .claude/handoffs/opencode-batch/mission-control-abc123.md). Open that file to see the agent's work and reasoning.

Q: I have a meeting at 14:00 UTC today. It's not a PRIORITY 1 item. Why not?

A: Only deadlines/meetings before 07:30 UTC (your buffer end) are PRIORITY 1. Meetings later in the day show in the calendar but are not marked urgent—you'll handle them when the time approaches.

Q: Can Grok see calendar events?

A: No. Grok runs in Cursor and does not have access to your Google Calendar. Only OpenCode (local) and the Learn Dashboard see your calendar. This is by design: Grok works on anonymized input only.

Q: The Learn Dashboard looks blank. What happened?

A: Likely causes:

  • No calendar events created for today
  • API backend is down (check with IT)
  • Your browser cached an old version (press Ctrl+Shift+R to hard refresh)

Click "Refresh Now" and check the browser console (F12) for errors.
