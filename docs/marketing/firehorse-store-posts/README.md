# Firehorse Store — Weekly Posts

Weekly customer-facing updates for the **Lifetime Firehorse™Store** on Google
Business Profile / Google Merchant Center. Posting little and often keeps the
store active in Search/Maps and reaches customers between purchases — sharing
news, new products, and special events at regular intervals.

- **Cadence:** weekly (publish Monday)
- **Channel:** Google Business Profile "What's New" post + one CTA button
- **Markets:** FI · SE · NO · DK · DE (feed targets these countries)
- **Languages:** Finnish (primary) + English. Add SE/DE if a campaign calls for it.
- **Store link (CTA):** https://dws10.com/buy/
- **Brand voice:** *Sovereign by Design. Global by Choice.* — verb-first, short, one offer per post.

## Files

One file per ISO week: `YYYY-Www_firehorse-store-post.md`
(e.g. `2026-W24_firehorse-store-post.md`).

## How to write the next week's post

1. Copy `_TEMPLATE.md` to `YYYY-Www_firehorse-store-post.md`.
2. Pick **one** featured offer from `dws10.com/config/products.json`
   (prefer a timely / seasonal / regulation-driven hook — e.g. AI Act, CSRD,
   CBAM, a new launch, or a special event).
3. Keep each language under ~1,500 characters (Google's post limit).
4. Set one CTA button (Learn more / Buy) pointing to `https://dws10.com/buy/`
   or the specific product page.
5. Suggest an image (EU blue `#003399` + gold `#FFCC00`, ≥1200×900px, < 5 MB).
6. Log the post in the table at the bottom of the file.

## Publishing (manual step)

Posts are drafted here and pasted into **Google Business Profile → Promote →
Add update** (or the Merchant Center storefront). Select the CTA, attach the
image, and publish. This repo holds the source copy and history.
