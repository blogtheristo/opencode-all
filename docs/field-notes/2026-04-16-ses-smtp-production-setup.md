## Human Action Required

### Step 1 — Create SES SMTP Credentials (AWS Console)

1. Log in to AWS Console → Region: **eu-north-1** (Finland)
2. Navigate to: **Amazon SES → SMTP Settings**
3. Click **Create SMTP Credentials**
4. IAM username: `dws6-ses-smtp` (or accept default)
5. Click **Create** — credentials shown **once only**, copy immediately:
   - `SMTP_USER` = the IAM SMTP username (starts with `AKIA...` — NOT the IAM access key)
   - `SMTP_PASS` = the IAM SMTP password (long random string — NOT the IAM secret key)
6. SMTP endpoint: `email-smtp.eu-north-1.amazonaws.com`
7. Port: `587`, STARTTLS (`SMTP_SECURE=false`)

> **Note:** The SMTP username/password are derived from IAM credentials but are NOT the same
> values. They are Base64-encoded HMACs generated by AWS specifically for SMTP AUTH.

### Step 2 — Verify Sender Domain

1. SES → **Verified Identities** → Add Identity
2. Type: **Domain** → `onelifetime.world`
3. Add the DKIM CNAME records to Cloudflare DNS (auto-detected if Route53)
4. Verify `risto@onelifetime.world` appears as a verified email identity

### Step 3 — Request Production Access

By default SES is in **sandbox mode** (200 emails/day, only verified recipients).

1. SES → **Account Dashboard** → Request Production Access
2. Use case: Transactional email (password resets, reports, notifications)
3. Expected volume: ~500 emails/day initially
4. Approval typically takes 24–48 hours

### Step 4 — Set Environment Variables

Add to production `.env` (Google Cloud Run secret or Cloud Run env var):

```
SMTP_HOST=email-smtp.eu-north-1.amazonaws.com
SMTP_PORT=587
SMTP_SECURE=false
SMTP_USER=<your-ses-smtp-username>
SMTP_PASS=<your-ses-smtp-password>
EMAIL_FROM=risto@onelifetime.world
```

For Google Cloud Run: use Secret Manager → create secrets → mount as env vars in
`gcloud run services update dws6run6 --set-secrets=SMTP_USER=...,SMTP_PASS=...`

### Step 5 — Smoke Test

```bash
# Test via the health endpoint (checks SMTP connectivity)
curl https://dws6.com/api/v1/health

# Or test directly with Node:
SMTP_HOST=email-smtp.eu-north-1.amazonaws.com \
SMTP_PORT=587 \
SMTP_USER=<user> \
SMTP_PASS=<pass> \
npx tsx -e "
import { sendEmail } from './src/utils/send-email.js';
sendEmail({
  from: 'risto@onelifetime.world',
  to: 'risto@lifetime.fi',
  subject: 'SES SMTP smoke test',
  html: '<p>SES is live.</p>'
}).then(console.log);
"
```
