2. Result: `C:\\Users\\risto\\.aspire\\bin\\aspire.exe` **13.5.4+9c1b401dd67746739044f68959cbf4d3d7af93a6**.
3. That SHA matches GitHub `microsoft/aspire` v13.5.4. NuGet `Aspire.Cli.*` 13.5.4 published 15.09.2026. 13.5 is stable (the 26.07.2026 note that “13.5.0 is preview” is superseded for the CLI).
