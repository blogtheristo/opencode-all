## How to log out #129 and #130

`#129` / `#130` are `loginctl` session ids, not Docker. On `gn100-cb5d`:

```bash
loginctl list-sessions
echo "this session: ${XDG_SESSION_ID:-unset}"
who
```

Type `exit` in every SSH window to this host (or close those windows). From Win11:

```powershell
ssh admin100@gn100-cb5d
```

If a session is leftover with no window and `echo $XDG_SESSION_ID` is `130`:

```bash
loginctl terminate-session 129
exit
```

Verify: `ps -p 1062639,1063661` prints nothing; new `$XDG_SESSION_ID` is not 129 or 130; `systemctl is-active docker` stays `active`.

Do not: `systemctl restart docker`, `systemctl restart gdm`, `loginctl terminate-user gdm`, `loginctl terminate-user admin100`, `reboot`.
