## Summary

The Red Queen Gödel Machine (RQGM) is an evolutionary framework for recursive self-improvement under non-stationary utilities. Unlike prior self-improving agent systems (including the Darwin Gödel Machine, arXiv:2505.22954) which assume a stationary evaluation criterion — a fixed verifier, benchmark, or labelled dataset that remains valid as the agent improves — the RQGM makes evaluation itself part of the improvement loop by co-evolving learned evaluators alongside the task agents they guide.

The name invokes Van Valen's Red Queen hypothesis from evolutionary biology: species do not optimise against a static environment but adapt as their environments change. The RQGM brings this principle to recursive self-improvement.

## Core Mechanism: Controlled Utility Evolution

- Search is organised into **epochs** with a fixed within-epoch evaluation criterion
- The utility function can be updated at **epoch boundaries**
- Self-improvement guarantees hold per epoch as the objective evolves across them
- Co-evolving learned evaluators improve alongside task agents
- The framework uses **Thompson sampling** over clade metaproductivity for node selection in a multi-agent workspace tree

## Architecture (Figure 2)

- Archive T containing nodes, each with K roles (generators r₁, r₂ and evaluators r₃, rₖ)
- Each node shares a workspace wₐ
- Evaluators scored against a **ground-truth anchor** (frozen per epoch) or a fixed benchmark for evaluator-independent roles
- **Checkpoint selection:** at epoch boundaries, frozen slot compares incumbent vs challenger evaluators on ground-truth anchor; ε-best-belief evaluator frozen for next epoch; utility records from displaced evaluator selectively erased
- Utility: U(a) = 1/K Σ\_{r∈R} P_r(a) — role-uniform & task-balanced within a role

## Key Results

1. **Coding tasks:** RQGM improves test pass rate over prior SOTA by adding a complementary agent-as-a-judge code-review signal; reviewer queried once (vs multi-turn evaluation); uses **1.35×–1.72× fewer tokens**
2. **Scientific paper writing & reviewing:** co-evolved writers reach **1.78×–1.86× higher acceptance rates** under a diverse agent-as-a-judge panel
3. **Olympiad-level proof writing & grading:** co-evolved graders reach **9% higher ground-truth accuracy**
4. **Reviewer calibration:** strongest baseline reviewer over-accepts AI-generated papers at up to **1.91× the human rate**; RQGM corrects this with an adversarial objective that discovers reviewers equally stringent on AI and human work

## DWS / Firehorse Relevance

### EAB-track extension

The RQGM formalises the temporal dimension the §14.19 EAB-track implicitly assumes: fixed benchmarks (even EAC1–EAC13) cannot keep pace with improving agents. Evaluators must improve too. Conformance vocabulary must evolve per epoch — a co-evolutionary KYA conformance attestation.

### CSB-track reinforcement

1.35×–1.72× fewer tokens on coding compounds the owned-compute advantage (§14.20 CSB-track). A self-improving system that also gets cheaper to run validates the capital-efficiency thesis (§14.24).

### Adversarial calibration for Article 12

The 1.91× over-acceptance finding implies that Article 12 logs generated by a fixed evaluator degrade in reliability as agents improve. Regulatory-grade logging requires periodic recalibration against ground truth.

### Maker–Checker Loop upgrade path

The single-query reviewer pattern (cheaper, more effective than multi-turn) maps to the Firehorse Maker–Checker Loop (§14.28): the checker could be a co-evolved evaluator rather than a fixed verification function.

### Flower Labs / federated sovereignty

Authors Jovanović and Sani are dual-affiliated Cambridge + Flower Labs (federated learning). This hints at federated co-evolutionary improvement where sovereign deployments share improvement signals without pooling data — compositional with §14.23 three-pillar sovereignty.
