# Field Note — Reachy Mini + NVIDIA Jetson AI Robotics Hackathon (27.06.2026)

_Event signal. Embodied AI + edge inference intersection. Relevant to sovereign-edge thesis (Jetson Orin = owned hardware) and world-model architecture (multimodal perception on physical agents)._

## Event

**Reachy Mini + NVIDIA Jetson AI Robotics Hackathon** — Santa Clara, CA, right after NVIDIA GTC 2026.

### Hosts

Seeed Studio, NVIDIA, Hugging Face, Pollen Robotics

### Focus

Multimodal AI, robotics agents, edge AI, real-world interaction.

## What participants build

Personal robot agent using:

- Reachy Mini humanoid robot (Pollen Robotics)
- NVIDIA Jetson Orin Nano edge AI computing
- Hugging Face models and apps
- Multimodal models: Gemma 3, Qwen3-VL, SmolVLM2, IBM Granite Vision, and others

Goal: deploy AI directly on a physical robot for real-time embodied intelligence.

## Why it matters

- **Jetson Orin = edge inference on owned hardware.** Same thesis as Control Room / Situation Room, different form factor.
- **Multimodal on-device.** Vision-language models running on Jetson Orin Nano validate that useful multimodal inference fits on edge hardware.
- **Embodied AI agents.** The agent architecture we build for industrial control rooms applies to physical robots — perception loop, action selection, safety constraints.
- **Hugging Face model ecosystem.** Open-weight models (Gemma 3, Qwen3-VL, SmolVLM2) running on edge devices reinforce the open-model sovereign-edge pattern.
