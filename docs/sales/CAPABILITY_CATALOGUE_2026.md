## Yhteenveto

DWS IQ 6 -alusta tarjoaa **80+ agenttikyvykkyyttä** organisoituna **10 LWM-ontologialuokkaan** (A–J). Kyvykkyydet kattavat koko arvoketjun EU-sääntelyn vaatimustenmukaisuudesta kenttäoperaatioihin ja myyntiautomaatioon.

## Kolmen pilarin konsultointimalli

Kyvykkyydet toimitetaan kolmen pilarin kautta:

1. **Kyvykkyysvalmennus** — Claude Code Coaching, agenttiontologian koulutus, käytännön harjoitukset
2. **Toimialakohtainen compliance-työnkulun kehitys** — Asiakaskohtainen agenttikokoonpano, tuotantokäyttöönotto, EU-sääntely-automaatio
3. **Häiriötön projektijatkuvuus** — Keskeytyslaskuri-validoitu siirtymä, nollakatkoisuustakuu
