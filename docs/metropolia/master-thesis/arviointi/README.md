Ohje siis nimenomaan **edellytti nimen päivittämistä**, ei alkuperäisen säilyttämistä.

Se ei ollut tulkintavirhe, joka jäi huomaamatta. **Se oli tulkintavirhe, joka huomattiin, oikaistiin ja jäi silti korjaamatta ennen peruuttamatonta askelta.** Tämä on tarkalleen se kuvio, jota vastaan `DWS_LEARNING_STANDARD.md` §10.3.1 (jäähdytysväli) on kirjoitettu — tunnettu korjaus, avoin aikaikkuna, eikä ketään joka veisi sen maaliin.
