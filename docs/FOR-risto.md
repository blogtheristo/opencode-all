## 5. Controversies

### 5.1 Calculator Restoration vs. Gamma Navigation

**Session:** `restore-calculator-TBPyS`
**Date:** 25.01.2026
**PRs:** [#275](https://github.com/blogtheristo/dws6/pull/275), [#276](https://github.com/blogtheristo/dws6/pull/276)

#### The Issue

When restoring the calculator section to landing pages, it conflicted with the previously implemented gamma navigation system. The first attempt (PR #275) restored the calculator but introduced duplicate navigation elements.

#### Timeline

1. **PR #275 (08:59):** Initial restore - calculator added but navigation duplicated
2. **PR #276 (10:12):** Fix applied - "Fix duplicate navigation and add comprehensive Home menu"

#### Resolution

The issue was resolved by:
1. Fixing the duplicate navigation components
2. Adding a comprehensive Home menu that works with both systems
3. Enabling universal gamma navigation

#### Lessons Learned

- **Test integration points:** When restoring removed features, ensure compatibility with changes made since removal
- **Atomic changes:** Consider the full impact of "restore" operations on interconnected systems
- **Quick iteration:** The issue was identified and fixed within ~1 hour, demonstrating effective rapid response

   - Removed dependency on deprecated `ai/react` import
   - Implemented standalone chat functionality with fetch API
   - Added proper TypeScript types for messages

2. **postcss.config.js** - Updated for TailwindCSS v4
   - Changed from `tailwindcss` to `@tailwindcss/postcss` plugin
   - Added required @tailwindcss/postcss dependency

3. **src/index.css** - Rewrote for TailwindCSS v4
   - Replaced `@tailwind` directives with `@import "tailwindcss"`
   - Converted `@apply` rules to standard CSS with CSS variables
   - Added `@theme` block for custom colors

4. **package.json** - Added missing dependencies
   - Added `@ai-sdk/react` package
   - Added `@tailwindcss/postcss` package
