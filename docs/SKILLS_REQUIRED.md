## Skills.sh Integration

### What is Skills.sh?

**Website:** https://skills.sh/
**Purpose:** Interactive skill assessments for developers

**Features:**
- Real coding challenges (not multiple choice)
- Timed assessments
- Instant feedback
- Skill certification badges
- Progress tracking

### How We Use It

**Hiring Process:**
1. Candidate completes relevant skills.sh assessments
2. Minimum scores required per role (see matrices above)
3. Failed candidates can retake after 30 days
4. Certificates valid for 12 months

**Continuous Learning:**
1. Quarterly skill assessments for team members
2. Identify knowledge gaps
3. Provide targeted training
4. Track improvement over time

**Onboarding:**
1. New hires take baseline assessment
2. Custom learning path based on results
3. Pair with mentor for weak areas
4. Re-assess after 90 days

### Recommended Learning Paths

**Path 1: Frontend Developer → Full Stack**
```
Week 1-2: TypeScript Fundamentals (skills.sh)
Week 3-4: React Advanced Patterns (skills.sh)
Week 5-6: Node.js & Express (skills.sh)
Week 7-8: PostgreSQL Queries (skills.sh)
Week 9-10: AI SDK Integration (Vercel docs + skills.sh)
Week 11-12: Build V9 Dashboard feature (hands-on)
```

**Path 2: Backend Developer → AI Specialist**

## Certification Program

### DWS IQ Platform Certified Developer

**Level 1: Associate Developer**
- Complete all skills.sh assessments (70%+ average)
- Build 3 dashboard features (code review approved)
- Pass DWS IQ platform quiz (80%+)
- Demonstrate CSRD knowledge (basic)

**Level 2: Professional Developer**
- Complete all skills.sh assessments (80%+ average)
- Build AI chat integration (production-ready)
- Contribute to open-source DWS components
- Deep climate regulation knowledge (CSRD, Fit 55)

**Level 3: Expert Developer**
- Complete all skills.sh assessments (90%+ average)
- Design new dashboard feature (accepted by team)
- Present at industry conference / write blog post
- Climate consultant level expertise

**Benefits:**
- Salary increase per level
- Speaking opportunities
- Mentorship responsibilities
- Training budget allocation
