## Markkinaehtoisuuden perustelu

**Profiilin määritelmä:**
- Senior Developer / Full-Stack Developer
- Pääasiallinen osaamisalue: pilvi-arkkitehtuuri, SaaS-kehitys, EU-regulaatioteknologia
- Kokemus: 10+ vuotta (Risto Anton Päärni, aloittanut ohjelmoinnin 2009)
- Viitekehykset: React, .NET, Azure, AWS, Google Cloud, Supabase
- Toimiala: legaltech / regtech / AI / compliance

**Lähteet:**
- Palkkavertailu.fi — IT-alan palkkahaku, senior developer Helsinki-alue
- Duunitori.fi — IT-alan palkkatilastot
- ICT-alan palkkatilastot (Teknologiateollisuus / Tietoala ry)

**Markkinavertailu (2024–2026):**

| Palkkalähde | Senior Developer Helsinki | Tuntihinta (laskennallinen) |
| :--- | :--- | :--- |
| Palkkavertailu.fi mediaani | ~6 000–7 500 EUR/kk | 37,50–46,88 EUR/h (palkka) |
| Konsulttihinnat (toimisto) | — | 80–150 EUR/h |
| Freelancer / itsenäinen konsultti | — | 75–120 EUR/h |
| **Aktivoinnissa käytetty** | — | **80–100 EUR/h** |

**Huomio:** Aktivoinnissa käytetty 80–100 EUR/h on **konsulttimarkkinan alaraja** senior developer -tasolle. Se on tahallisesti konservatiivinen — todellinen markkinahinta itsenäiselle senior developer -konsultille on tyypillisesti 100–120 EUR/h tai enemmän.

## Yhteys IAS 38:aan

IAS 38 (aineettomat hyödykkeet) sallii kehittämismenojen aktivoinnin laskennalliseen arvoon perustuen markkinaehtoiseen palkkatasoon, kun:

1. Tekijä on tunnistettavissa ✓ (Risto Anton Päärni)
2. Palkkataso on markkinaehtoinen ✓ (80–100 EUR/h = konservatiivinen konsulttihinta)
3. Tunnit ovat luotettavasti mitattavissa ✓ (käänteiskirjausmenetelmä + ETK)
4. Hanke on tunnistettava ✓ (DWS IQ -tuoteperhe)
