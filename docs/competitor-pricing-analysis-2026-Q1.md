## 4. Pricing Position Analysis

### 4.1 DWS IQ Pilot Model vs. Market

**Enterprise Navigator (€4,950 kertamaksu, 3 kk) — kilpailuasema:**
- Halvempi kuin Greenlyn vuositaso (€5,800 Climate Action)
- Sisältää ERP-integraation + CSRD-raportin, mitä Greenly EI tarjoa missään hinnassa
- CFO-ystävällinen: alle €5K kynnys, ei vaadi hallituksen hyväksyntää useimmissa yrityksissä
- Ei sido jatkotilaukseen — asiakas voi kävellä pois riskittä
- Optionaaliset laitteistot: Control Room €4,990 + Situation Room €4,990
- **Verdict:** Erinomainen entry point — halvempi kuin kilpailijoiden vuosisopimus, mutta sisältää enemmän

**Enterprise Premium (alkaen €8,950/vuosi, €746/kk) — kilpailuasema:**
- 1.2–1.5x Greenly (€5,800–€7,200) — mutta sisältää ERP-liittimet + 18 AI-agenttia
- 3–9x halvempi kuin Sweep enterprise (€40K–€80K)
- 6–26x halvempi kuin Persefoni (€50K–€230K)
- 5–27x halvempi kuin Watershed (€45K–€240K)
- **Verdict:** Optimaalinen "underserved middle" -hinta. Sisältää kaiken mitä kilpailijat tarjoavat €50K+ hinnalla

**Enterprise Nordic (alkaen €25,950/vuosi) — kilpailuasema:**
- 1.5–3x halvempi kuin Sweep enterprise (€40K–€80K)
- 2–9x halvempi kuin Persefoni/Watershed enterprise
- Custom-integraatiot, SLA, dedicated support
- **Verdict:** Uskottava enterprise-taso, silti merkittävästi halvempi kuin kilpailijat

**Enterprise World (neuvoteltava) — kilpailuasema:**
- Räätälöity sopimus, oma instanssi, white-label
- Sisältää DGX Spark Situation Room — private cloud + dedicated NVIDIA DGX compute
- Tekee Enterprise World:sta täysin oman kategorian vs. kilpailijat
- **Verdict:** Kilpailijoilla ei vastaavaa tarjontaa — ainoa EU-suvereeni full-stack AI + laitteisto

### 4.2 Pilot → Annual -suppiloanalyysi

```
Enterprise Navigator (€4,950)    ← 3 kk, 1 ERP, CSRD-raportti, koulutukset, Captain-esittely, Fit55
    ↓ konversio (tavoite: >70%)      Ei sido jatkotilaukseen
Enterprise Premium (€8,950/yr)   ← Kaikki 18 agenttia, ERP, prioriteettituki
    ↓ upsell
Enterprise Nordic (€25,950/yr)   ← Custom-integraatiot, SLA, dedicated
    ↓ upsell
Enterprise World (neuvoteltava)  ← Oma instanssi, white-label, DGX Spark Situation Room
```

**Suppilon vahvuudet:**
1. €4,950 Navigator on impulssiostos enterprise-budjetissa — ei sido jatkotilaukseen
2. Navigator sisältää koulutukset ja Captain-esittelyn — ei tarvita erillistä tutustumisvaihetta
3. Navigator-tulokset = todistettu ROI → Premium-konversio luonnollinen
4. Premium → Nordic → World upsell-polku kun organisaation tarpeet kasvavat
5. Enterprise World on täysin oma kategoria — DGX Spark Situation Room erottaa kilpailijoista

**Suppilon riskit:**
1. Navigator 3 kk voi olla liian lyhyt monimutkaisille ERP-integraatioille
2. "Ei sido jatkotilaukseen" = asiakas voi lähteä — konversion laatu ratkaisee

### 4.3 DWS Unique Differentiators (Price-Relevant)

1. **Enterprise Navigator** — Ainoa kilpailija joka tarjoaa low-risk entry pointin ilman jatkositoumusta. Persefoni/Watershed vaativat enterprise-sopimuksen heti
2. **Nordic ERP Connectors** — Visma, Monitor, Jeeves, IFS. 0 kilpailijalla
3. **EU-hosted (Finland)** — Datasuvereniteetti vs. US-pohjainen Persefoni/Watershed
4. **21 AI agents** — Automaatio vs. manuaalinen consultant-malli
5. **Hinnoittelu kattaa kaiken** — Ei piilokustannuksia, ERP-integraatio sisältyy pilot-hintaan

## 5. Strategic Recommendations

### 5.1 Enterprise-hinnoittelumalli on kilpailukykyinen
Navigator → Premium → Nordic → World -malli ratkaisee aiemmat aukot:
- **Entry barrier:** Navigator €4,950 < Greenly annual €5,800, ei sido jatkotilaukseen
- **Value for money:** Premium €8,950 sisältää ERP + 18 agenttia (kilpailijat: €50K+)
- **Enterprise ceiling:** Nordic €25,950 on uskottava, silti 2–10x halvempi kuin kilpailijat
