## Founder Positioning (Public, LinkedIn, 2026-09-21)

Tobias's own framing of Sync Motion's product philosophy:

> "A lot of infrastructure products have become unnecessarily complicated. File transfer is a good example. For many companies, the requirement is still simple: Move files securely from A to B. Keep access controlled. Know what happened. Don't spend time maintaining the server. That's basically the idea behind what we're building at Sync Motion. Managed infrastructure for problems that still need to work every day."

**Why this matters for outreach:** This is a simplicity-first, managed-infrastructure pitch — not a data-science or AI pitch. A DWS IQ approach should speak the same language: "you own getting the data out reliably; we own turning it into a defensible answer." Leading with AI/compliance jargon risks missing his register.

**Alignment framing (DWS IQ's read, not validated with Tobias):**

- Sync Motion: "know what happened" — data layer, managed, audit-native
- DWS IQ: "know what it means" + "prove it" — decision layer, mandate evidence chain
- Clean separation of concerns, if he sees it the same way
