## The 13 Signals

**1. The harness is the new distribution channel.**
Isenberg's first point: be the tool the agent's harness loads by default, the way desktop and mobile platform defaults minted giants. The Scope read: distribution moats are reforming around MCP registries and harness defaults, not app stores. Whoever is registered where agents shop gets discovered by machines, not marketers. DWS codified this as an operating rule — every production capability ships with CLI, structured JSON, and MCP exposure.

**2. Agent spend is the next cloud-bill shock.**
"One bad loop spends $100 in tokens in eight minutes." Enterprises that learned cloud FinOps the hard way are about to relearn it at agent speed. The Scope read: spend control bolted on as a finance tool fails, because the spender has no stable identity. Budget enforcement belongs in the governance layer, bound to an agent identity — which is why this signal and signal 6 are the same product. Continuity note: this is the week-21 token-pricing capitulation signal, now visible from the demand side.

**3. Memory becomes infrastructure — but only audited memory.**
"Become the shared brain agents read and write to and you become infrastructure." True, and dangerous: a shared brain without provenance is a poisoning target. The Scope read: the winning memory layer will be the one that can answer _where every fact came from_. DWS runs this as the dual LWM + client memory architecture with a governed fact-extraction audit trail.

**4. Sandboxes get productized.**
"You obviously don't hand an agent your real Stripe account." A category "nobody's clocked" — except it is the founding pillar of Know Your Agent: verify the human, sandbox the agent. MicroVM isolation plus zoned permissions (full-auto / logged / human-required) is already how DWS sessions run; an agent here physically cannot reach a live payment write without a human. Expect this to become procurement's first checkbox question within a year.

**5. Docs became the runtime interface.**
Humans click around for ten minutes; agents onboard by reading. Your documentation is now your product's API surface. The Scope read: the quality bar moves from "helpful for developers" to "machine-onboardable" — versioned, structured, drift-proof (generated from code, not written about it). Companies whose docs lie will discover that agents, unlike humans, act on the lie at scale.

**6. Trust gets priced.**
"Agents get scammed by other agents. A track record you can check becomes real money." The Scope read: agent reputation is about to become an underwriting input, exactly as credit scores did. DWS already computes an Agent Trust Score with an executable engine and financial multipliers — higher-trust agents are literally cheaper to run and insure. Watch for the first insurer to ask for an agent's score.

**7. Authority binding is the keystone signal.**
An agent must prove it acts for a real person with real spend authority. This is the point the other twenty stack on: without verified human-to-agent binding, spend controls leak, escrow can't release, disputes have no defendant, and liability has no address. KYC providers moving into agent attestation (the Shufti-class play) is the tell. The Scope read: the permission layer is where the value pools — and it is a governance product, not a fintech product.

**8. Verification is the hard half of machine money.**
"Escrow that releases when the job is verified done, no human checking." The rails are commodity; the trustworthy _done_ signal is not. The Scope read: quality gates that emit signed completion attestations become the integration point every escrow, marketplace, and warranty product consumes. Related: proving _physical_ work (Isenberg's robot points) is the same signal at industrial scale — site sensors and SAR-satellite change detection already do it for heavy industry.

**9. Forensic replay flips from debugging tool to compliance artifact.**
"Someone will build the 'why did my agent do that' replay and it'll be mega valuable." In the EU it is not merely valuable — EU AI Act Article 12 record-keeping makes it mandatory for high-risk deployments, with Article 99(4) penalties (€15M / 3%) for deployers who can't produce it. The Scope read: the US will sell replay as observability; the EU will require it as evidence. Build once, to the stricter spec.

**10. Multi-vendor failover is sovereignty by another name.**
"A human hits rate limits and shrugs. An agent hits them and the whole workflow dies." The Scope read: surviving one vendor's rate limiter and surviving one vendor's jurisdiction is the same architecture — a model router plus owned inference you control. DWS runs Claude, Gemini, Llama and Qwen behind a tier router with failover to self-hosted models on owned NVIDIA hardware when limits hit or a prompt must stay EU-resident.

**11. The always-on box comes back.**
Agents need to live somewhere 24/7. After a decade of serverless abstraction, the pendulum swings back to residency: a persistent machine with a filesystem, cron, and no per-token meter. The Scope read: this rhymes with the owned-compute bet — flat-rate sovereign hardware against metered clouds — and it is why single-tenant sovereign tiers exist. The agent's home address is becoming a procurement question: whose box, whose jurisdiction, whose meter?

**12. Machines get wallets — governance first, wallet second.**
Warehouse robots paying for compute, home robots ordering parts, agents hiring humanoids. The Scope read: a spending machine is just an agent with actuators. It needs an identity, a trust score, a budget ceiling, and a named human-in-command _before_ it needs a card number. The fleet-dispatch systems running today (software tasking devices inside one owner's fleet) are the single-owner precursor of the machine-labor marketplace — and the trust layer, not the marketplace, is the durable position.

**13. Agent behavior gets version control.**
"When your agent gets worse overnight, you need to roll back the exact skill that broke it." The Scope read: this is the quiet one that matters most for enterprises. Prompts, skills, and standards need git-grade history with named authorship per change — which agent changed what, when, in which session — plus learning loops where improvements are proposed by machines and applied by humans. That pattern exists and runs in production today; packaging it is the opportunity.

## The Scope Meta-Read

Isenberg's list is 21 startups. Read through the governance lens, it is three products and a doctrine. Spend control, trust scores, authority binding, verified-done, replay, disputes, virtual cards, liability — eight of his points are one governed layer. Memory, docs, and versioning are the substrate an agent fleet runs on. Always-on boxes, fleets, and physical verification are the sovereign runtime. And the doctrine: in the EU, that governance layer is not a nice-to-have startups compete to sell — the AI Act makes it mandatory infrastructure. The internet was built for people. This wave gets built for machines — and the machines will be regulated before they are rich.
