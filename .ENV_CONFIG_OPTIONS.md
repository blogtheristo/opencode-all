# .env.mcp - 4 Configuration Options

**Version:** 1.0 (2026-01-11)

Sinulla on 4 vaihtoehtoa `.env.mcp` konfigurointiin. Valitse sopivaksi:

---

## Option 1: MINIMAL (Recommended for MVP)

**Käyttötarkoitus:** Pienin mahdollinen konfiguraatio  
**Tiedoston koko:** ~15 rivit  
**Aika:** 1 min täyttää  
**Sopii:** Kehitys, testaus

```env
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_KEY=eyJhbGc...
SUPABASE_ANON_KEY=eyJhbGc...
ANTHROPIC_API_KEY=sk-ant-...
MCP_HUB_PORT=8765
ENVIRONMENT=development
DEBUG_MODE=true
```

**Edut:**

- ✓ Nopea täyttää
- ✓ Selkeä rakenne
- ✓ Vain kriittiset arvot
- ✓ Helppo muistaa

**Haitat:**

- ✗ Ei muita palveluja
- ✗ Ei monitoring
- ✗ Ei production-ready

---

## Option 2: DOCKER (For Container Development)

**Käyttötarkoitus:** Docker Compose -käyttöön optimoitu  
**Tiedoston koko:** ~30 riviä  
**Aika:** 3 min täyttää  
**Sopii:** Container-pohjainen kehitys

```env
# Core
MCP_HUB_PORT=8765
MCP_HUB_HOST=0.0.0.0
ENVIRONMENT=development
DEBUG_MODE=true

# Supabase
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_KEY=eyJhbGc...
DATABASE_URL=postgresql://postgres:password@db.your-project.supabase.co:5432/postgres

# AI Models
ANTHROPIC_API_KEY=sk-ant-...
GROQ_API_KEY=gsk_...
# Baseten EU — custom/fine-tuned model deployment, EU residency
# Sign Baseten DPA before routing EU customer data; model = deployment ID
BASETEN_API_KEY=your-baseten-api-key
BASETEN_BASE_URL=https://bridge.baseten.co/v1/direct
BASETEN_MODEL=your-deployment-id

# Docker Volumes
POSTGRES_DATA_PATH=./data/postgres
TEMPORAL_DATA_PATH=./data/temporal
LOGS_PATH=./logs

# Network
NETWORK_NAME=mcp-hub-network
CORS_ALLOWED_ORIGINS=http://localhost:3000,http://localhost:3001

# Security
MCP_HUB_API_KEY=dev-key-change-in-prod
```

**Edut:**

- ✓ Docker Compose -valmis
- ✓ Tietokanta-yhteydet
- ✓ Volume-konfiguraatio
- ✓ Network setup

**Haitat:**

- ✗ Hieman pidempi
- ✗ Tarvitaan Docker-tietoa

---

## Option 3: PRODUCTION (Full Featured)

**Käyttötarkoitus:** Tuotantokäyttöön, kaikki palvelut  
**Tiedoston koko:** ~80 riviä  
**Aika:** 5 min täyttää  
**Sopii:** Staging, QA, Production

```env
# Core
MCP_HUB_PORT=8765
ENVIRONMENT=production
DEBUG_MODE=false

# Supabase (all)
SUPABASE_URL=...
SUPABASE_SERVICE_KEY=...
SUPABASE_ANON_KEY=...
DATABASE_URL=...

# AI Models
ANTHROPIC_API_KEY=...
GROQ_API_KEY=...
GOOGLE_API_KEY=...

# Security
MCP_HUB_API_KEY=...
JWT_SECRET_KEY=...
MCP_HUB_AUTH_ENABLED=true
RATE_LIMIT_ENABLED=true

# Payments
PAYPAL_CLIENT_ID=...
PAYPAL_SECRET=...
STRIPE_SECRET_KEY=...

# Email
RESEND_API_KEY=...

# Monitoring
ENABLE_METRICS=true
METRICS_PORT=9090

# Cloudflare (if using)
CLOUDFLARE_ACCOUNT_ID=...
CLOUDFLARE_API_TOKEN=...
```

**Edut:**

- ✓ Kaikki palvelut
- ✓ Production-ready
- ✓ Monitoring
- ✓ Full security

**Haitat:**

- ✗ Paljon muuttujia
- ✗ Monimutkaisempi
- ✗ Kaikkia ei tarvitse

---

## Option 4: CLOUD ONLY (GCP / Azure)

**Käyttötarkoitus:** Google Cloud Run / Azure App Service  
**Tiedoston koko:** ~5 riviä (loput Cloud Secrets)  
**Aika:** 1 min täyttää  
**Sopii:** Cloud deployment

```env
# Local dev only - production values in Cloud Secrets Manager

SUPABASE_URL=https://dev-project.supabase.co
SUPABASE_SERVICE_KEY=dev-service-key
ANTHROPIC_API_KEY=dev-key

# In production: use Google Secret Manager or Azure Key Vault
# PRODUCTION_SUPABASE_URL=GCP_SECRET:supabase_url
# PRODUCTION_API_KEY=GCP_SECRET:anthropic_key
```

**Edut:**

- ✓ Minimaalinen local .env
- ✓ Secrets Manager käytössä
- ✓ Production safe
- ✓ Nopea

**Haitat:**

- ✗ Vaatii Cloud setup
- ✗ Monimutkaisempi infrastructure
- ✗ Lisäkustannukset

## How to Choose

### 👉 **Use MINIMAL if:**

- [ ] Aluillaan MVP kanssa
- [ ] Lokaali kehitys vain
- [ ] Haluut yksinkertaisuutta
- [ ] Ei maksuja vielä

### 👉 **Use DOCKER if:**

- [ ] Käytät Docker Compose
- [ ] Kehität containerissa
- [ ] Tarvitset tietokannan locally
- [ ] Multi-service setup

### 👉 **Use PRODUCTION if:**

- [ ] Staging/QA/Prod
- [ ] Kaikki palvelut käytössä
- [ ] Maksut, email, monitoring
- [ ] Vakaa konfiguraatio

### 👉 **Use CLOUD ONLY if:**

- [ ] Deployt Google Cloud / Azure
- [ ] Käytät Secret Manager
- [ ] Infrastructure-as-Code
- [ ] Maksimaalinen turvallisuus
