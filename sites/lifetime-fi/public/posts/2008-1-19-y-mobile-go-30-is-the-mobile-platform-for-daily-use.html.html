Y! mobile Go 3.0 is the mobile platform for daily use

Published on January 19, 2008

Hello Mobile Lifestyle people!Are you constantly on the run?

There is one tool that fits your lifestyle. Y! Mobile Go.  

I downloaded Y! Go 2.0 first time to my Nokia E61 device in December 2007 and I do like it more and more. Look and feel is clear and stress less. Using application  became my favourite which I would even add word addictive.

Now the Y! Go 3.0 (Beta) is also available. This time I'm using N series phone to gather experience of the new mobile platform.

Improvements I missed in Y! go 2.0 (Revisited):


1. In Mail:           I would like to see the list of mails and delete some of mails without opening them.

Good thing is to see yahoo mail effortlessly. Could there be support for gmail as well? 

2. RSS and Atom feed support for Business blogs 

This seems to be OK. Using One Search is working fine..

3. In Web:          support html x.x for browsing more. I want Lifetime Oy Retro page to look and feel the way it is!

I got to the web browser of the mobile phone but going back is not easy!

4. Secure pop mail support for other email accounts, like local IMAP mail boxers and hotmail more

I'm not sure if this feature is there? 

5. Connection to Fring and Y! IM would be important?

 Also 3G to 4G and to 7G speeds later on will improve service creatly. Adding that Myspace support will certainly add more and more usage for Y! Go Mobile.

Overall weight: This stuff is cool. And it is getting serious.

Y! Go 2.0 Mobile:    Lifetime Scope Rank: 4 stars out of 5.

Y! Go 3.0 Mobile:    Beta Effort Rank: 4 stars out of 5. (Keep running..)
