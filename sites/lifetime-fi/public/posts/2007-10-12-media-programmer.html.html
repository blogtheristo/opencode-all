Media programmer

Published on October 12, 2007



 
 


Miksi työskentelisit juuri Lifetime Oy Media  Programmerina?

TietoEnator yhdistää vankan media-alan tuntemuksen ja uuden teknologian alalle tarjoamien mahdollisuuksien syvällisen ymmärtämisen. Tarjoamme media-alalle markkinoiden parhaat arvoa lisäävät tietotekniikkapalvelut. Tarjoomamme media-alalle ja sisällöntuottajille koostuu kahdesta tasosta: Laajamittaiset kumppanuudet ja toistettavat cross-media ratkaisut. Vahva asemamme media-alan asiakkaiden parissa auttaa meitä palvelemaan yrityksiä nopeasti yhdistyvissä liiketoimintaympäristöissä, joissa hyödynnämme kaikkea TietoEnatorin osaamista ja synergioita. Asiakkaitamme ovat tällä hetkellä mm. SanomaWSOY, Alma Media, MTV3 ja Talentum.

1. Java-arkkitehti/-kehittäjä, digitaalinen media (Espoo) - Haluatko luoda tulevaisuuden ratkaisuja kansainvälisten asiakkaidemme kanssa hyödyntäen uusimpia teknologioita?

Tehtävänäsi on toimia ohjelmistosuunnittelijana ja -arkkitehtinä digitaalisen median alueen projekteissamme. Olet mukana suunnittelemassa ja toteuttamassa innovatiivisia tulevaisuuden ratkaisuja asiakkaillemme mm. mobiili-tv:n, internet-tv:n ja mainonnan alueella. Osallistut ratkaisuiden määrittelyyn, arkkitehtuurisuunnitteluun ja toteutukseen.

Pidät monipuolisista tehtävistä, olet ulospäin suuntautunut ja toimit luontevasti asiakasrajapinnassa. Sinulla on sopivasti kunnianhimoa ja nautit asiakkaan ongelmien ratkaisemisesta.

Edellytämme sinulta vahvaa palvelinpuolen Java -osaamista. Suunnittelemme ja toteutamme järjestelmiä mm. Tomcat-, JBOSS- ja BEA WebLogic -ympäristöihin, joten arvostamme myös osaamista joltain em. alueista. Lisäksi eduksesi on osaaminen web- ja mobiiliratkaisuiden kehittämisestä ja Web 2.0 tekniikoista, kuten Ajax.

2. Arkkitehti (Espoo) - Toimiiko arkkitehtuurisi myös reaalimaailmassa?

Tehtävänäsi on kehittää asiakkaittemme tietojärjestelmistä Web services- ja SOA-pohjaisia, välineinä mm. UML, Java ja J2EE. Termit kertovat sinulle myös sen mitä tarvitsemme. Hanskaat UML-pohjalta lähtevän Java-pohjaisen verkkoarkkitehtuurin määrittelyn ja suunnittelun, etkä vierasta toteutustehtäviäkään.

Haasteenasi on rakentaa asiakkaittemme ydinjärjestelmät toimimaan kolmitasoarkkitehtuurin mukaisesti. Arkkitehtuurisi näkyy käyttäjille sovelluksina, jotka toimivat verkossa sujuvasti. Olipa tämä mielestäsi pala kakkua tai kova haaste, niin tule kokeilemaan siipiäsi. Niin tai näin, hyvälle tekijälle löytyy aina hyviä tehtäviä.

3. Ohjelmistosuunnittelija (Tampere tai Espoo) - Työskenteletkö mielelläsi sekä itsenäisenä konsulttina asiakkaiden kanssa että projektiryhmän jäsenenä?

Tehtävänäsi on jatkokehittää ja ylläpitää verkkopohjaista oppimisympäristöä. Edellytämme sinulta mm. Visual Basic, SQL, XML, XSL ja ASP -osaamista. Tulevien työtehtävien kannalta myös .NET-osaaminen on eduksesi. Jos sinua voisi luonnehtia luovaksi ongelmanratkaisijaksi, jolta ei puutu asiakastyön edellyttämiä sosiaaliakaan taitoja, tartu tilaisuuteen.

4. Java Enterprise -sovelluskehittäjä (Espoo) - Haluatko päästä vaikuttamaan siihen mitä ja miten asioita tehdään?

Toimit ohjelmistosuunnittelijana sovelluskehitysprojekteissa, joita teemme mediataloille. Ymmärrät hajautettuja sovelluksia ja integraatioalustoja. Sinulla on vahva kokemus J2EE-ympäristöstä, joissa on käytössä Enterprise Java Beans, JSP ja MVC frameworks(Struts), JNDI, JDBC ja XML. Edellytämme sinulta myös kokemusta formaaleista ohjelmistokehityksen metodeista ja web-käyttöliittymäkehityksestä, kuten Css, JavaScript, Html. AJAXin osaaminen on sinulle plussaa. Arvostamme myös osaamistasi Oracle-tietokannoista, WebSphere Application Serveristä, Windowsista ja Linuxista. Lue alta lisää siitä, mitä me tarjoamme sinulle.
