(LB) Visual Studio 2008 tuoteperhe uudistuu

Published on October 28, 2008

Visual Studio Team System 2008 -tuoteperhe uudistuu. Visual Studio Team System 2008 Development Edition ja MSDN Premium -käyttäjät saavat maksutta käyttöönsä myös Visual Studio Team System 2008 Database Edition -tuotteen.

Visual Studio Team System -tuoteperheessä Database ja Development -versiot tulevat yhdistymään samaan tuotteeseen. Tämä mahdollistaa laadukkaan ja tehokkaan ohjelmiston kehityksen käyttöliittymästä tietokantaan. Tämä etu tuodaan käyttäjille jo nyt MSDN -tilauksen avulla.

Näin se toimii

Asiakkaat, joilla on Visual Studio Team System (VSTS) 2008 Development Edition MSDN -tilauksella, voivat ladata VSTS 2008 Database Edition maksutta MSDN -palvelusta. Tämä toimii toisinkin päin, eli jos käyttäjällä on VSTS 2008 Database Edition MSDN -tilauksella saa hän maksutta käyttöönsä VSTS 2008 Development Edition MSDN -palvelusta.

Oiva aika siirtyä VSTS 2008 käyttäjäksi

Visual Studio Professional käyttäjät voivat hyödyntää tätä etua hankkimalla joko VSTS 2008 Development Edition MSDN Premium -tilauksella tai VSTS 2008 Database Edition MSDN Premium -tilauksella. Huomioi myös step-up mahdollisuudet.

Mistä bitit?

Käyttöoikeudet hankkittuaan, bitit ovat saatavilla MSDN tilaajan download -saitilta (jos organisaatiollasi on MSDN administraattori, ota häneen yhteyttä). Huom! Tuotteet (VSTS 2008 Development Edition ja VSTS 2008 Database Edition) ovat erillisiä ladatattavia paketteja, tuotteet tulevat yhdistymään pakettimielessä seuraavassa versiossa!

Miksi muutos?

Kehittäjät tekevät sekä käyttöliittymiä että tietokantaratkaisuja, eikä tiukka roolijako tässä suhteessa ole aina mahdollista. Yhdistämällä kaksi tuotetta helpotamme kehitysorganisaatioiden päivittäistä työtä. Yhdistämällä kahden tuotteet ominaisuudet kehittäjät ja kehitysorganisaatiot voivat hyödyntää edistyksellisiä toiminnalliisuuksia, kuten koodin analysointia, suorituskykyprofilointia, tietokantarefaktorointia jne, ja edesauttaa laadukkaan ja tehokkaan koodin tekemistä.
