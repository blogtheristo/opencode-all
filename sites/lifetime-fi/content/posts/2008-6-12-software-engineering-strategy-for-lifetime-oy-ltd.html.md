Whether you&#8217;re building applications for standalone desktop, client/server workgroups, or multi-tiered enterprise - choosing the right development tools is crucial to project success.<em><strong>&#8221; [Codegear Ad,June 2008]</strong></em><br /></p><p align="justify" style="text-align: justify;">I programmed first time 1984 with Commodore 64 and Simon&#8217;s basic. From those early coding days I have been involved with tens of software engineering projects. In the early MS Windows days the Borland (Today CodeGear) tools were among the most used, namely Borland Pascal 3.0 and Borland C 1.5 and 2.0. I really liked to write code those days, so getting back to the code level is really exciting. I have promised not to take any crappy administrative projects that would brake my learning process.<span class="full-image-float-right"><img alt="CodeGear_diagram_300px_042308.gif" src="http://images.squarespace-cdn.com/content/v1/54c48881e4b0d7a7fa7eddf4/1425316454595-E3UTUOJWETJYY2PBNSAN/CodeGear_diagram_300px_042308.gif" /></span></p><p>1991 I graduated from Espoo-Vantaa, and that summer I wrote somewhat first text in Finnish about Object- Oriented Programming as a process (Olio-ohjelmointi,1991, Suomen atk-kustannus). This text was full of error translations (no one had made translations earlier anywhere) and mistakes (and yes misunderstanding), but the meta-data level of the Software Engineering as a process were somewhat semantically correct at the time. There were English compilation that used somewhat similar approach until 1999 widely used in Universities.<br /></p><p> Later on, a book called Ohjelmistotuotanto by professor Ilkka Haikala and Director Jukka M&auml;rij&auml;rvi from Nokia Software Division were published as late as 1995 that included much needed update and corrected the whole process. </p><p>I found the eight edition of Ohjelmistotuotanto from public library. The book offer all-round view of the discipline of Software Engineering 1.0. Book is widely used in Academic courses in various Universities in Finland.</p><p>&nbsp;</p><p><span class="full-image-float-right"><a href="http://cordis.europa.eu/en/home.html" target="_blank" class="offsite-link-inline"><img alt="Sevent_Framework" src="http://images.squarespace-cdn.com/content/v1/54c48881e4b0d7a7fa7eddf4/1425316454696-71A992MLKC6V0B6GNXL2/Sevent_Framework Software Architecture. Three layer model is a good start with SOA&nbsp; and EAI. Using Web Services bring more asyncronous possibilities and outsourcing of services. </p><p align="justify" style="text-align: justify;">But this is only the beginning.
