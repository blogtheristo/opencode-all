  <div src="v5"><p align="justify" style="text-align: justify;">In Lifetime Studios, the engine for our new productions, one of the first things about the new production is estimating its commercial potential. Every production is a piece of art, but also it has to grasp the financing before the go decision is made to the project. The Customer will have to have some basic budget for the production. This budget base is then translated into preliminary project plan for the first screening consultation meeting. I many cases the project turns out not to be financed at this stage. </p><p align="justify" style="text-align: justify;">&nbsp;</p><p align="justify" style="text-align: justify;">However, as the Japanese companies case studies teaches us, the planning phase for any project is always much more inexpensive, than running the actual project. The worst case scenario for any productions is to start it from the scratch without decent planning phase.<br /></p></div>
