Visual Studio Team System 2008 Development Edition ja MSDN Premium -k&auml;ytt&auml;j&auml;t saavat maksutta k&auml;ytt&ouml;&ouml;ns&auml; my&ouml;s Visual Studio Team System 2008 Database Edition -tuotteen.<br /> <br /> Visual Studio Team System -tuoteperheess&auml; Database ja Development -versiot tulevat yhdistym&auml;&auml;n samaan tuotteeseen. Huom!
