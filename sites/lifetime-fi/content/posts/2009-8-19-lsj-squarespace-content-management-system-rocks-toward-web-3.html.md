  <div src="v5"><p>Thank You Squarespace folks !</p>
<p>I can honestly say that editing and writing is cool with the all new Squarespace 5 Blog tools is a pleasure cruise !</p>
<p>Using different templates and banners ,showing various columns depended by the page user is, all of this works now effortlessly. Editing the text is cool and easy. etc. etc. The list goes on and on.</p>
<p>My hope would be, that all the entries I (plus my friends) have in Facebook, Delicious, Twitter, Twine etc. would somehow interact to keep all 1500+ blog and other&nbsp;entries up to date. This I suppose, will be one of the main features of Web 3.0. Using tools like Facebook Connect the way forward is now happening.</p>
<p>I imagine, that semantically linked data is like a dynamic books shelf of criss-cross magazines, where changing one word&nbsp; in a criss cross would automatically&nbsp;start a synchronated&nbsp;update to all the books. In those cases, where automation would not be good enough, the system management&nbsp;would&nbsp;help me to correct those criss-cross pages that need my actions.</p>
<p>In the front row with all the best web 2.0 services, Squarespace Content Management System Rocks toward Web 3.0.</p></div>
