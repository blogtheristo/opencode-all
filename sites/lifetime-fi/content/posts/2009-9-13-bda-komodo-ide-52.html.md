  <div src="v5"><p><strong>Komodo 5.2 Coming Soon!</strong></p>
<p><br />Komodo IDE 5.2 is now in Beta, and scheduled for release mid-September.</p>
<p>Along with some performance and stability improvements,&nbsp;ActiveState Crew has&nbsp;added a lot of new things:</p>
<p><br />Ruby: Debugging support for Ruby 1.9.1 and up.<br />PHP: New PHP 5.3 support: <br />Code browser and section list support for namespaces<br />Code completions for /Namespaces<br />Syntax coloring of latest keywords (&#8220;namespace&#8221;, &#8220;use&#8221;, &#8220;as&#8221;, etc&#8230;)<br />Updated Xdebug builds to support PHP 5.3<br />&#8230;plus some debugging configuration improvements: <br />Improved debugger wizard for the first time setup<br />Support for a wider range of PHP builds on Windows<br />Sub-language background colors: You can now give sub-languages a different background color in multi-language buffers.<br />View HTML Source: Drag and drop an http:// or https:// URL onto Komodo to see the contents of the page.</p></div>
