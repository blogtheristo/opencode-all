# DWS IQ Sales Package Validation Framework

## Package Validation Checklist

### 1. Buyer Validation
- [ ] Clear, named buyer identified
- [ ] Concrete business problem articulated
- [ ] Specific industry or use case defined
- [ ] Pain points clearly stated
- [ ] Value proposition specific to this buyer

### 2. Claim Validation
- [ ] All claims can be supported by repository evidence
- [ ] Technical boundaries clearly defined
- [ ] Legal compliance requirements verified
- [ ] No unsupported guarantees or outcomes
- [ ] Claims bounded by actual architecture or contracts

### 3. Pricing Validation
- [ ] Price matches canonical source (dws10.com/price-list/)
- [ ] Billing unit consistent with description
- [ ] No contradictory pricing in description vs price
- [ ] Setup fees and recurring fees clearly separated
- [ ] Tiered pricing explained with clear boundaries

### 4. Delivery Validation
- [ ] Clear timeline with realistic duration
- [ ] Specific prerequisites defined
- [ ] Acceptance criteria measurable
- [ ] Success metrics quantified
- [ ] Capacity limits stated

### 5. Legal Boundary Validation
- [ ] No unsupported compliance claims
- [ ] No unverified security assertions
- [ ] All provider names verified in live architecture
- [ ] No unproven performance claims
- [ ] No misleading or exaggerated outcomes

### 6. Commercial Viability
- [ ] Clear next step for prospect
- [ ] Value proposition compelling enough to drive action
- [ ] Price point appropriate for target buyer
- [ ] No missing components that would block sale
- [ ] All prerequisites clearly communicated
