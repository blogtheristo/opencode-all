================================================================================
                          FEATURES
================================================================================

Authentication Flow:
  User enters credentials
    ↓
  Frontend validates input
    ↓
  POST to /api/v1/auth/login
    ↓
  Backend checks rate limit (5/15min)
    ↓
  Verify password with bcrypt
    ↓
  Generate JWT token (24h) + refresh token (7d)
    ↓
  Return to frontend
    ↓
  Store tokens in localStorage
    ↓
  Redirect to dashboard

Dashboard Access:
  Check localStorage for token
    ↓
  If no token → Redirect to login
  If token exists → Load dashboard
    ↓
  Display user info + tutorials

Token Refresh:
  Access token expires (24h)
    ↓
  Frontend detects 401 error
    ↓
  POST /api/v1/auth/refresh
    ↓
  Backend generates new token
    ↓
  Frontend updates token
    ↓
  Retry original request
