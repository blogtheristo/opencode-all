🔧 SETUP NEEDED (30 minutes)
─────────────────────────────────────────────────────────────────────────────

1️⃣  Add dws6.com to Cloudflare (5 min)
    → https://dash.cloudflare.com
    → Add site → dws6.com
    → Copy Cloudflare nameservers

2️⃣  Update Nameservers at Registrar (5 min)
    → Suomen Internet (or your registrar)
    → Update DNS: Use Cloudflare nameservers
    → Wait: 15-48 hours for propagation

3️⃣  Create Cloudflare Pages Project (10 min)
    → Pages → Create Project → Connect Git
    → Repo: blogtheristo/dws6
    → Build output: landing-pages/dws6-com

4️⃣  Connect Custom Domain (5 min)
    → Pages → Settings → Domains
    → Add: dws6.com
    → Verify CNAME record

5️⃣  Configure SSL/TLS (2 min)
    → SSL/TLS → Full (strict)
    → HSTS: Enable with preload
    → Min TLS: 1.2

6️⃣  Test Deployment (2 min)
    → Visit: https://dws6.com/login
    → Check: HTTPS lock icon ✅
    → Share button: Working! ✅
