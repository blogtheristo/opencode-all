# DWS IQ Catalog Audit Report

## Executive Summary

This audit analyzes the current DWS IQ product catalog to identify which products qualify as "SERIOUS" for sales purposes, which are "HIC" (Hold/In-Development/Clarification needed), and which are "HOLD" (not ready for separate sales motion).

## Audit Criteria

A product is **SERIOUS** if it meets all of the following criteria:
1. Named buyer
2. Concrete business problem
3. Defined deliverable
4. Current price and billing unit
5. Delivery prerequisites
6. Measurable acceptance or success criteria
7. Credible path to paid deployment

A product is **HIC** (Hold/In-Clarification) if it has a material issue such as:
1. Contradictory pricing
2. Unsupported legal/compliance claims
3. Unclear delivery capacity
4. Missing buyer
5. Missing acceptance criteria
6. Dependency confusion
7. Inconsistent SKU/subscription data

A product is **HOLD** if it is:
1. Experimental
2. Duplicative
3. Too narrow
4. Hardware variant
5. Generic consulting
6. Internal component
7. Not ready for a separate sales motion
