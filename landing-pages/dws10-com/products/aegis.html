Command Line Interface

Every Aegis agent is accessible via the dws CLI — zero-dependency Node.js, JSON-native output, pipeable into any automation pipeline. No GUI required.

Command What It Does
dws agents List all 21+ agents with status and capabilities
dws run compliance --input '{"industry":"steel"}' Run EU compliance assessment — CBAM, ETS, CSRD, Fit for 55
dws sovereignty-assess CLOUD Act exposure scan, EU data residency verification
dws workflow compliance-assessment Multi-agent compliance + emissions + supply chain cascade in one call
dws kya snap KYA safety snapshot — agent trust scores, active MicroVM sessions
dws run site-safety --input '{"site":"HEL-01"}' SiteSense safety scoring — EN 13001, weather risk, crane warnings
dws fleet scan Discover Lifetime Fleet robots on network, return JSON device list
dws fleet kya snap <robot-id> KYA governance snapshot for a specific robot — trust score, kill-switch state
dws kb ask "CSRD E1 disclosure requirements" Query the DWS knowledge base — regulatory text, standards, field notes
dws mcp tools List all MCP tools exposed at the /mcp endpoint for agent-to-agent calls
dws health Backend + MCP endpoint health check — connectivity, auth, agent availability

All commands output structured JSON by default (--format table for human use). Pipeable: dws discover carbon | dws run emissions-data-analyst --stdin
