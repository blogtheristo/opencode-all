VPK example — Sovereign control room for a volunteer fire brigade

The scenario: A vapaapalokunta gets an alarm at 02:14. The duty officer needs to call the right crew, check the response zone, log the dispatch — and have an audit trail that survives an EU oversight visit. The internet is flaky in the kalustohalli. Doing this through a cloud LLM is not a plan.

Here's how Control Room covers it without leaving the building:

  • Voice in: Whisper-large-v3 transcribes the duty officer's situation report straight from a USB mic — Finnish, dialect-tolerant, fully local.
  • Dispatch reasoning: Qwen 2.5 72B reads the transcript + the brigade's roster + the response SOPs, suggests crew composition and equipment list. Operator confirms or overrides.
  • SMS / Virve text: structured-output model formats the dispatch message and pushes it to the radio gateway. No cloud LLM in the loop.
  • Log: every prompt, every response, every operator decision lands in the Article 12 immutable log on local NVMe. 7-year retention. Sealable for incident review.
  • Replay later: after the call, the same Control Room helps the brigade write the official incident report from the captured transcript and dispatch log — in minutes, not hours.
