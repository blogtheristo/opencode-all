Architecture Overview

DWS IQ 6 follows a Brain-Memory-Body-Hands architecture where specialized AI agents collaborate through the Model Context Protocol (MCP) to handle complex industrial tasks while maintaining full EU regulatory compliance.

Specialized Industry Agents

Each industry vertical has a purpose-built agent that inherits from a common base class. Agents use different cognitive reasoning patterns optimized for their domain.

Industry Agent Pattern Key Capabilities
Logistics LogisticsAgent ReAct Route optimization, Kela transport, driver dispatch
Construction ConstructionAgent ReAct Tilaajavastuu, YTJ verification, safety index
Compliance ComplianceAgent Chain-of-Thought NIS2 reporting, GDPR requests, EU AI Act
Energy EnergyAgent Tree-of-Thought Fingrid data, grid optimization, ETS tracking
Healthcare HealthcareAgent Chain-of-Thought DVV integration, patient data, GDPR handling
Manufacturing ManufacturingAgent ReAct Supply chain, CBAM reporting, Traficom
Public Sector PublicSectorAgent Chain-of-Thought Suomi.fi, DVV population register
Financial Services FinanceAgent Reflexion FIN-FSA compliance, risk assessment
Cognitive Patterns: Each agent uses the reasoning pattern best suited to its domain. ReAct for tool-using tasks, Chain-of-Thought for step-by-step compliance analysis, Tree-of-Thought for multi-option optimization, and Reflexion for self-correcting financial assessments.
