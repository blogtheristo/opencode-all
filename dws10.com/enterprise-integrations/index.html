Read-and-act, not read-only

Dashboards tell you what happened. DWS IQ takes the next step: every integration is bidirectional. We ingest telemetry, reason on it with the Lifetime World Model, then write actions back to the source system — setpoint changes, work orders, purchase requisitions, supplier flags, regulator filings.

Integration lifecycle:

  • Ingest — stream or batch pull from the source (Building X API, SAP S/4HANA, Siemens Desigo CC, IFS, Dynamics, MES, IoT).
  • Reason — Lifetime World Model evaluates against live EU regulation set (CSRD, EPBD, CBAM, Taxonomy, Fit for 55). DWS IQ agents plan interventions.
  • Act — writeback to the source: HVAC setpoint adjustments, maintenance work orders, CBAM supplier questionnaires, automated ESRS datapoint submission, Taxonomy CapEx tagging, renovation-passport triggers.
  • Audit — every action recorded with reasoning lineage to Aiwen audit tables (Article 12) and signed with the Aegis provenance chain.

Every integration ships with:

  • EU-sovereign data path — payloads processed in Helsinki (Aiven), Hamina (Google Cloud europe-north1), or Paris/Amsterdam (Scaleway). No US routing in Aegis tier.
  • KYA-gated writeback — every action is attested to a verified human operator (Know Your Agent). Leash Snap (TC-4) lets the customer revoke agent write authority instantly.
  • DWS IQ Aegis provenance chain — signed report and action output suitable for ESRS assurance providers and regulator audits.
