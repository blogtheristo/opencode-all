Lifetime Oy Positions KYA as the Identity Spine Beneath MCP Apps — Every New Open Standard Under AAIF Makes Know Your Agent More Necessary, Not Less

Following the AAIF MCP Apps launch that turns Model Context Protocol servers into interactive UIs rendering inside ChatGPT, Claude, Goose, and VS Code, Lifetime Oy publishes its position: interactive agent surfaces need more identity binding, not less. KYA (Know Your Agent) is the identity spine beneath the MCP Apps fabric — agents bound to verified humans, revocable by TC-4 Leash Snap.

HELSINKI — Lifetime Oy today published its public position on the AAIF MCP Apps launch, which turns Model Context Protocol servers into interactive UIs that render inside host applications — ChatGPT, Claude, Goose, and VS Code. The launch expands the agent surface area dramatically: every MCP server can now render UI, trigger tools, and chain actions across hosts.

Lifetime Oy's position: more open standards under the Agentic AI Foundation (AAIF) make Know Your Agent (KYA) more necessary, not less. When an MCP App renders inside ChatGPT and fires a tool call against an enterprise back-end, the question is no longer "is the prompt safe?" — the question is "who is the agent, who authorised it, and can we revoke its access in one action?"

"MCP Apps extends the frontier. KYA is the spine underneath. You cannot have interactive agent surfaces firing inside consumer chat without a verifiable identity binding each agent to a real human — and a TC-4 Leash Snap that can terminate the chain the moment trust degrades. Every new open standard makes KYA more necessary, not less." — Risto Paarni, Founder & CEO, Lifetime Oy

What KYA provides beneath MCP Apps:

  • Agent-to-human binding — every agent session cryptographically tied to a verified human identity
  • Trust scoring — real-time score per session, auditable via the /kya skill
  • TC-4 Leash Snap — chain termination primitive; revokes an autonomous agent mid-run
  • EU AI Act Article 12 audit trails — every agent decision logged, signed, and retained
  • MicroVM isolation — per-agent sandboxing aligned with the Aiven and Scaleway sovereign stack

KYA Standard v1.5 was published in April 2026 with an expanded field-note on how the standard evolved since v1. The full technical story, including how KYA plugs into the MCP Apps fabric, is available on Lifetime World.

Lifetime Oy Confirms the EU-Sovereign Stack: Aiven (Helsinki) + Scaleway (Paris) + KYA — 21 Skilled Compliance Agents Per Client, Sandboxed and Identified

Responding to Satya Nadella's Microsoft Foundry post, Lifetime Oy publishes the architecture underneath DWS IQ 6: Foundry solves the sandbox half of the agent-isolation problem; KYA solves the identity half. The sovereign ground underneath is Aiven (Helsinki) and Scaleway (Paris). Each EU client gets 21 skilled compliance agents running in per-client MicroVMs, bound to verified human operators — no CLOUD Act exposure.

HELSINKI — Lifetime Oy today confirmed the architecture underneath DWS IQ 6 following Microsoft CEO Satya Nadella's Foundry post describing a unified sandbox plus model routing stack for enterprise agents. Lifetime Oy's position: Foundry describes the half we have been shipping. The other half is KYA. The layers underneath are Aiven and Scaleway.

The four solid layers:

  • Layer 1 — Aiven (Helsinki). Managed Postgres, Kafka, OpenSearch on EU-sovereign regions. Finnish-headquartered, no CLOUD Act exposure.
  • Layer 2 — Scaleway (Paris). European cloud compute, bare-metal, and managed Kubernetes for the workloads that need to stay in France or Germany.
  • Layer 3 — MicroVM sandboxes, per client. Foundry-style isolation — each of the 21 skilled compliance agents runs in its own MicroVM, with per-client tenancy. Solves the sandbox half.
  • Layer 4 — KYA (Know Your Agent). Agent identity spine. Every agent cryptographically bound to a verified human operator. TC-4 Leash Snap for instant revocation. Solves the identity half.
"Nadella's Foundry post describes the half we have been shipping. The sandbox half. The other half is KYA — the identity spine that tells you which agent is which, authorised by whom, and revocable in one action. The layers underneath are Aiven in Helsinki and Scaleway in Paris. That is the EU-sovereign ground. Twenty-one skilled compliance agents per client, properly wired." — Risto Paarni, Founder & CEO, Lifetime Oy

What this means for DWS IQ 6 customers:

  • 21 Skilled Compliance Agents per EU client — each sandboxed, identified, auditable
  • Zero CLOUD Act exposure — Helsinki + Paris data residency, Finnish + French jurisdictional sovereignty
  • EU AI Act Article 12 audit trails out of the box
  • Deterministic model-agnostic orchestration — swap Claude for Gemini or Groq without losing the World Model

Defence and dual-use supply chains face the same EU compliance obligations as civilian industry — CSRD, CBAM, NIS2, and the EU AI Act — plus export control (EU Reg. 2021/821), data sovereignty requirements, and dual-use classification.
