How It Works

  1. Assess: Run dws sovereignty-assess against your database config. Get a score, tier, and gap report.
  2. Plan: The Sovereignty Monitor agent generates a migration roadmap with effort estimates.
  3. Migrate: We handle the migration to EU-sovereign infrastructure with zero downtime.
  4. Monitor: Continuous sovereignty agent runs daily checks, alerts on drift, and maintains compliance evidence.

Technical Specifications

  • Database: PostgreSQL 16+ (Supabase EU, Hetzner, OVHcloud, self-hosted)
  • Scoring: 8-dimension sovereignty assessment (data residency, CLOUD Act, encryption, RLS, GDPR, backups, access control)
  • Agent: Sovereignty Monitor — continuous compliance with HIL escalation when confidence < 80%
  • Output: JSON (CLI/API), PDF (board reports), Supabase dashboard
