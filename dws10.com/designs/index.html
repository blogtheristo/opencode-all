How Pretext Powers This Page

The editorial hero above uses zero DOM measurements. Every line is placed by pure arithmetic.

⚡

prepare() → layout()

Text is segmented and measured once via prepareWithSegments(). Then layoutNextLine() flows each line around the orbs with different widths per row.

🌀

Obstacle Routing

Golden orbs are animated via requestAnimationFrame. Each line's available width is carved by circle-band intersection — text reflows live, 60fps.

🎨

ASCII Particle Field

120 particles orbit attractors. A brightness field decays and splats. Characters are chosen from .:-=+*#%@ by brightness — all at 60fps.
