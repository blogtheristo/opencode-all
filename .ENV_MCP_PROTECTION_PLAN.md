# Protect .env.mcp from Being Lost

**Problem:** .env.mcp disappears randomly, likely due to Proton Drive sync issues  
**Solution:** Create backup and auto-restore mechanism  
**Created:** 2026-01-11

---

## Problem Analysis

Your `.env.mcp` file keeps disappearing:
- ❌ Not a hacking issue
- ❌ Not git corruption
- ⚠️ **Likely Proton Drive sync issue** causing file loss

**Why it happens:**
1. Proton Drive syncs and conflicts occur
2. File gets marked as "conflicted" or temporarily moved
3. Git merge or sync operation removes it
4. Result: `.env.mcp` vanishes

---

## Solution: Backup & Auto-Restore

### Step 1: Create Backup Folder

```powershell
cd "D:\Proton\My files\2026\Repos2026\dws6"
mkdir -p "Admin/.env-backups"
```

### Step 2: Manual Backup Strategy

Save `.env.mcp` in THREE places:

**Location 1: Git-ignored backup (LOCAL)**
```powershell
# Create backup
Copy-Item ".env.mcp" -Destination "Admin/.env-backups/.env.mcp.backup-$(Get-Date -Format 'yyyy-MM-dd-HHmmss')"

# List backups
Get-ChildItem "Admin/.env-backups/" | Sort-Object LastWriteTime -Descending
```

**Location 2: Your Notes/Password Manager**
- Store muuttujien ARVOT (ei tiedostoa) salasananhallintajärjestelmässäsi
- Esim. LastPass, 1Password, Bitwarden

**Location 3: OneDrive / Cloud Personal**
- Varmuuskopio `.env.mcp`:stä omassa OneDrive-kansiossasi
- Erillään Proton Drive -synkroinnista

## Step 3: Auto-Restore Script

Jos `.env.mcp` katoaa, voit palauttaa sen automaattisesti:

```powershell
# Script: Restore-EnvMcp.ps1

param(
    [switch]$Auto  # Automatically restore without asking
)

$projectRoot = Get-Location
$envMcpPath = Join-Path $projectRoot ".env.mcp"
$backupPath = Join-Path $projectRoot "Admin/.env-backups"
$examplePath = Join-Path $projectRoot "env.mcp.example"

# Check if .env.mcp exists
if (Test-Path $envMcpPath) {
    Write-Host "✓ .env.mcp exists" -ForegroundColor Green
    exit 0
}

Write-Host "⚠️  .env.mcp NOT FOUND!" -ForegroundColor Yellow

# Try to restore from backups
$backups = Get-ChildItem $backupPath -Filter ".env.mcp.backup-*" -ErrorAction SilentlyContinue | 
    Sort-Object LastWriteTime -Descending

if ($backups.Count -gt 0) {
    $latestBackup = $backups[0]
    Write-Host "Found backup: $($latestBackup.Name)" -ForegroundColor Cyan
    
    if ($Auto -or (Read-Host "Restore from backup? (Y/n)") -ne "n") {
        Copy-Item $latestBackup.FullName -Destination $envMcpPath
        Write-Host "✓ Restored from backup" -ForegroundColor Green
        exit 0
    }
}

# Fallback: restore from env.mcp.example
if (Test-Path $examplePath) {
    Write-Host "Fallback: restoring from env.mcp.example" -ForegroundColor Yellow
    Copy-Item $examplePath -Destination $envMcpPath
    Write-Host "✓ Restored template (you'll need to re-fill values)" -ForegroundColor Yellow
    exit 0
}

Write-Host "❌ No backup or template found!" -ForegroundColor Red
exit 1
```

### Usage:

```powershell
# Manual restore with prompt
pwsh -File .\scripts\Restore-EnvMcp.ps1

# Automatic restore (no prompt)
pwsh -File .\scripts\Restore-EnvMcp.ps1 -Auto
```

## Step 4: Add to Git Pre-Commit Check

Edit `.git/hooks/pre-commit` (or create it):

```bash
#!/bin/bash
# Pre-commit hook: Protect .env.mcp

if [ ! -f ".env.mcp" ]; then
    echo "⚠️  WARNING: .env.mcp missing!"
    echo "Creating backup before continuing..."
    
    # Try to restore
    if [ -f "env.mcp.example" ]; then
        cp env.mcp.example .env.mcp
        echo "✓ Restored .env.mcp from template"
    else
        echo "❌ Cannot restore .env.mcp"
        exit 1
    fi
fi

exit 0
```

Make executable:
```bash
chmod +x .git/hooks/pre-commit
```

## Step 5: Proton Drive Sync Workaround

### Temporarily Disable Sync (During Development)

If Proton Drive keeps interfering:

1. **Right-click** Proton Drive folder
2. Select **Properties → Sync** 
3. **Pause sync** for 1 hour
4. Work on `.env.mcp`
5. Resume sync when done

### OR: Move Outside Proton Drive

```powershell
# Create .env.mcp in local folder (NOT synced)
$env.mcp = "C:\dev\.env.mcp"  # Outside Proton Drive

# Symlink from repo
New-Item -ItemType SymbolicLink -Path "D:\Proton\...\dws6\.env.mcp" -Target "C:\dev\.env.mcp"
```
