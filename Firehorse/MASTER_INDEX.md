## 🚀 Implementation Guide

### Step 1: Database Setup (30 minutes)

```bash
# Deploy Supabase schema
psql -f supabase-schema-templates.sql

# Verify tables
psql -c "\dt"

# Check sample data
psql -c "SELECT COUNT(*) FROM carbon_factors;"
```

### Step 2: Python Environment (15 minutes)

```bash
# Install dependencies
pip install -r requirements.txt

# Set up environment
cat > .env << EOF
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_KEY=your-anon-key
EOF

# Test installation
python -c "from report_engine import FirehorseReportEngine; print('✓ OK')"
```

### Step 3: Load Templates (15 minutes)

```python
from report_engine import FirehorseReportEngine

engine = FirehorseReportEngine()

# Templates are automatically loaded from templates/ directory
template = engine.load_template_config('EN 15978', 'Pan-European')
print(f"✓ Loaded: {template['templateName']}")
```

### Step 4: Generate First Report (15 minutes)

```python
# Generate EN 15978 carbon report
pdf_content = engine.generate_carbon_report(
    project_id='PROJECT-001',
    standard='EN 15978',
    language='en',
    output_format='PDF'
)

# Export to file
output_file = engine.export_report(
    content=pdf_content,
    format='PDF',
    output_path='./reports',
    filename='carbon_report_PROJECT-001.pdf'
)

print(f"✓ Report generated: {output_file}")
```

### Step 5: Validate Compliance (15 minutes)

```python
# Fetch data
project_data = engine.fetch_project_data('PROJECT-001')
carbon_data = engine.fetch_carbon_data('PROJECT-001')

# Load and populate template
template = engine.load_template_config('EN 15978', 'Pan-European')
populated = engine.populate_template(template, {**project_data, **carbon_data})

# Validate
errors = engine.validate_compliance(populated, 'EN 15978')

if errors:
    print(f"✗ Validation failed: {len(errors)} error(s)")
    for error in errors:
        print(f"  - {error}")
else:
    print("✓ Report is compliant!")
```

**Total Setup Time**: ~90 minutes
