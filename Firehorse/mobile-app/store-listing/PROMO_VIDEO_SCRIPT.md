## 📱 Screen Recording Guide

### Setup
```bash
# Option 1: Android Emulator
1. Open Android Studio
2. Start Pixel 6 emulator (1080x2340)
3. Run app: npm run android
4. Enable "Show taps" in Developer Options
5. Start screen recording

# Option 2: Real Device
1. Install app on Android phone
2. Enable "Show taps" in Developer Options
3. Connect to computer via USB
4. Use scrcpy for screen mirroring:
   scrcpy --record firehorse-demo.mp4
```

### Recording Checklist
- [ ] Clean app state (no test data)
- [ ] Good lighting (if filming device)
- [ ] Stable camera/mount
- [ ] Show taps enabled
- [ ] Battery icon hidden
- [ ] Time set to 10:00 AM
- [ ] Notifications cleared
- [ ] Smooth, deliberate gestures
