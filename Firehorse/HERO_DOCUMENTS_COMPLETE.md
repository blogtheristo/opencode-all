## 💻 Käyttöönotto

### 1. EN 15978 Hiilijalanjälki

```python
from report_engine import FirehorseReportEngine

engine = FirehorseReportEngine()

# Generoi kuukausittainen raportti
pdf = engine.generate_carbon_report(
    project_id='FI-OFFICE-2024',
    standard='EN 15978',
    language='fi',
    output_format='PDF'
)

engine.export_report(pdf, 'PDF', './reports')
```

### 2. Työmaapäiväkirja

```python
# Päivittäinen päiväkirja - 70% automaattinen!

    date='2025-12-30',
    language='fi'
)
```
