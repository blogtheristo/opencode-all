## 📊 Valmis Dokumentti: EN 15978 Hiilijalanjälki

### Kentät (Yhteensä 50+ kenttää)

**Kansilehti (7 kenttää)**
- Projektikoodi (NCC-tyyli) ⭐
- Projektin nimi
- Raportointipäivä
- Versio
- Logo

**Tiivistelmä (6 kenttää) - HERO SECTION**
- Kokonaishiilijalanjälki ⚡
- Hiili-intensiteetti ⚡
- Budjetin tila 🚨
- Budjetin käyttöaste 🚨
- Fit for 55 -status 🇪🇺
- Audit Trail -linkki 🔗

**Projektitiedot (7 kenttää)**
- Projekti-ID
- Rakennustyyppi
- Sijainti
- Bruttoala
- Tarkastelujakso
- Aloitus/valmistuminen

**Elinkaaren Päästöt (20+ kenttää)**
- A1-A3: Tuotevaihe + materiaalitaulukko
- A4: Kuljetus + kuljetustaulukko
- A5: Rakentaminen
- B1-B7: Käyttövaihe
- B6: Käyttöenergia ⚡
- C1-C4: Elinkaaren loppu
- D: Hyödyt

**Fit for 55 / CSRD (4 kenttää) - HERO SECTION**
- EU Taxonomy -yhteensopivuus 🇪🇺
- DNSH-arviointi
- Tekniset arviointiperusteet
- CSRD-tagit

**Suositukset (3 kenttää)**
- Vähentämismahdollisuudet
- Materiaalien vaihdot
- Seuraavat toimenpiteet

**Allekirjoitukset (8 kenttää)**
- Laatija + päivä + allekirjoitus
- Hyväksyjä + päivä + allekirjoitus
- Varmentaja + päivä (valinnainen)

## 🚀 Käyttöönotto

### Python-esimerkki:

```python
from report_engine import FirehorseReportEngine

# Alusta engine
engine = FirehorseReportEngine()

# Lataa Hero-dokumentti
template = engine.load_template_config('EN 15978', 'Pan-European')

# Generoi raportti
pdf_content = engine.generate_carbon_report(
    project_id='FI-OFFICE-2024',
    standard='EN 15978',
    language='fi',
    output_format='PDF'
)

# Vie tiedostoon
output_file = engine.export_report(
    content=pdf_content,
    format='PDF',
    output_path='./reports',
    filename='hiilijalanjälki_FI-OFFICE-2024.pdf'
)

print(f"✓ Raportti luotu: {output_file}")
```
